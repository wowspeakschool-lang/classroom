# Банк игр для урока и тренажёра (идеи Анны, 21.10.2026)

Каждая игра 1–2 минуты. Для ребёнка у игры игровая цель (помочь Penguin, поймать, найти), для учителя — учебная. В уроке звука нет: слово говорит учитель.

| игра | как | когда годится |
|---|---|---|
| Послушай и выбери | учитель говорит слово, ребёнок выбирает картинку (как в тренажёре, без написания) | с 2 слов |
| Правда или нет | картинка + учитель говорит слово, ребёнок: yes / no | с 2 слов |
| Что под снежком? | микроб прячет вещи под снежки, учитель: «О нет, микроб прячет вещи, чтобы мы не нашли!»; снежок трясётся — угадай, открываем | с 3 слов |
| What's missing? | одна вещь пропадает — какая? | с 4 слов |
| Найди пары | открой карточку и назови слово | с 3–4 слов |
| Увеличенная картинка | картинка сильно увеличена и постепенно уменьшается — назвать как можно быстрее | любая |
| Облачко / размытие | картинка под облачком или размыта, постепенно проясняется — угадать | любая |
| Плитки | картинка закрыта прямоугольником, квадратики исчезают по одному — угадать раньше всех | любая |
| Лови! | вещи падают медленно, ребёнок ловит названную; микробов не ловить | с 4 слов |
| Стоп! | вещи едут по ленте, в рамку попадает названная — ребёнок кричит «Stop!» | с 3–4 слов |
| Поможет или нет? | из сугробов торчат вещи, в том числе несуразные (валенок, рыбка, сосулька) — поможет против микробов? | ввод слова |
| Жесты (mime) | учитель показывает жест — ребёнок называет, и наоборот | ввод и отработка |
| Покажи | учитель называет слово — ребёнок показывает жест, всё быстрее | отработка |
| Найди дома | ребёнок приносит к камере такую же вещь | отработка |
