# New Year — решения Анны (27.11.2026)

Порядок работы: уроки делаем по очереди, первым 4–6. Каждый сюжет доводим «до идеала» тогда,
когда до него дойдём; сейчас — только направление.

## 4–6 — «Звёздочка для ёлки дракона» (сюжет принят)
- Целевые слова — зимние/праздничные: star, snowflake, snowman, present; кандидаты — Santa, elf, carrot.
  Сомнение Анны: snowman и snowflake похожи — решить при разработке (в пользу snowman).
- hat, scarf — не целевые, просто встречаются в истории: «Дует ветер, что поможет?» — зонтик, шарф,
  что-то смешное; ребёнок выбирает шарф, учитель говорит «scarf».
- По дороге дракон встречает героев (Santa, elf…), от каждого получает подарок (present) —
  в финале подарки ложатся под ёлку.
- Игра «Создай своего снеговика»: собрать и украсить (морковка, шапка, шарф, пуговицы).
  ВАЖНО: детали должны ложиться друг на друга красиво и соразмерно — продумать слои и точки крепления
  заранее, проверить скриншотами до показа Анне.

## 7–9 — «Внутри снежного шара» (сюжет принят)
Слова подбираем, когда дойдём: сначала история, потом слова, которые ей нужнее всего.

## 10–12 — «Один дома»: помоги Кевину подготовить дом к приходу воров
- Задания → ловушки. Ловушки безобидные (фильм жёсткий — у нас мягко).
- Продумать подачу для beginners (нулевые).
- Видео-вставки: семья Кевина → Кевин один (вопросы: с кем ты встречаешь Новый год? хотел бы один?) →
  воры собираются → «покупаем» ловушки → ловушки сработали → воров забирает полиция.
- Advanced: разговор о семье и праздниках.
- Фрагменты видео ищет и режет Анна.

## 13+ — «Around the World at Midnight» (сюжет принят)
- Видео о том, как празднуют в разных странах; реальные фотографии стран.
- Слова обсудим позже.

## Для всех уроков
- Extra tasks, как в Halloween — для каждого урока свои.
- Новые игры на отработку лексики, не только прежние. Идея Анны: «Поймай» — внизу персонаж
  с корзинкой, его водят мышкой/пальцем влево-вправо, сверху падают предметы (работает и с телефона).

## 27.11.2026 — видео из «Один дома» не показываем (решение Анны)
Сюжет 10–12 остаётся (подготовить дом к ворам), но без кадров фильма и без имени Кевина.
Варианты вместо фрагментов (выбор за Анной, пункт 28):
- свой мультфильм-заставка из наших картинок: сцены с плавным движением камеры, звуки, голос учителя;
- комикс-история по кадрам, учитель читает, дети реагируют;
- стоковые видео с бесплатной коммерческой лицензией (Pexels, Pixabay): снег за окном, семья у ёлки,
  салют — для настроения и вопросов «а ты как встречаешь?»; для 13+ — праздники в разных странах;
- официальный трейлер студии только встраиванием с YouTube — как разминка, по желанию.
