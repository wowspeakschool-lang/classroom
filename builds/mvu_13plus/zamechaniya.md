# Вводный урок 13+ — замечания Анны (копим, правим по команде «приступай к правкам»)

1. (06.11) Приветствие: на экране оставить только «Welcome to WowSpeak School!». Остальной текст («это не тест…», «отвечай как получается…») убрать с экрана — его говорит преподаватель (перенести в план, teacher's language).
2. (06.11) «Get to know you»: не показывать три вопроса сразу. Одна карточка — один вопрос: нажал на карточку → следующий вопрос, и так до третьего. Кнопка Next делает то же самое (если преподаватель забыл, что надо нажимать на карточку): сначала листает вопросы, после последнего — переход дальше. **Так на каждом этапе**, где несколько вопросов/пунктов: показывать по одному, Next и нажатие листают их по очереди (в т. ч. «And you?», где несколько вопросов).
