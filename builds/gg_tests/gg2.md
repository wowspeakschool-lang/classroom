## A. Проверено и чисто — перепроверять не нужно

Это централизованные проверки запросами по всем 145 блокам, не чтением.

| проверка | результат |

| Дубли среди вариантов одного вопроса | нет ✔ |

| Качество картинок в тестах | из 415 картинок курса меньше 300 px — 17, и в тестах используется только одна: `gg2/u1/calculator.webp` (255×299). После правки диктанта она остаётся — на грани, перерисовывать не обязательно |
| `audio_tts` в блоках аудирования | нет ни в одном ✔ (место под запись сохранено) |

Разбор движка подтвердил два правила, на которые опирались правки:

- `classroom__norm` = `lower()` + схлопывание пробелов. Регистр в `accept`
  значения не имеет (поэтому `["biscuits","Biscuits"]` — безвредная
  избыточность), **а апостроф значения имеет**: `'` и `’` — разные символы.
- `order` сверяется **по значению плитки**, не по индексу, поэтому одинаковые
  плитки в одном предложении (`I'm … I'm`) блок не ломают.
