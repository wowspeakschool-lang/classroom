# SM0 · Unit 0 — что здесь лежит

Ничего из этого **не залито** в базу: Classroom переезжает на WowSpeak Team,
до переезда заливка запрещена. Файлы собраны так, чтобы их можно было достать
и перенести в любой момент, в том числе из другой сессии.

| файл | что это |
|---|---|
| `build.py` | сборка: держит содержимое уроков и выдаёт SQL и JSON |
| `u0_hw1.sql` · `u0_hw1.json` | **Homework 1** юнита 0, собрана по плану «Lesson 1 (Hello)». В базе её не было: на её месте лежит копия Homework 4 юнита 1 |
| `u0_test.sql` · `u0_test.json` | **тест юнита 0** к уроку Lesson 6 «Revision + Test» |
| `u0_test_sostav.md` (папкой выше) | состав теста человеческим языком |

SQL — для текущей схемы (`classroom_lessons` / `classroom_blocks`), запускается
в SQL Editor целиком, идемпотентен: повторный запуск перезапишет блоки, а не
удвоит их. JSON — то же содержимое без привязки к схеме: если на WowSpeak Team
таблицы окажутся другими, уроки собираются из него.

Пересобрать после правок: `python3.13 builds/sm0/u0/build.py`
Проверить перед заливкой: `python3.13 tools/val.py builds/sm0/u0 sm0/legacy`

## Что нужно от методиста

* Записать **звук /s/ и /æ/** (звук, не имя буквы) — ДЗ 1, блок 2, вопросы 1 и 2.
  Пока там пустое `audio`.
* Нажать «Озвучить пачкой» для фраз Hello! / What's your name? / How are you? /
  I'm Misty — они помечены `audio_tts`. Решение методиста: эти фразы синтезом.
* Решить, что делать с чужой «Homework 1» юнита 0 (сейчас `sort_order` 1).
  Новая ДЗ 1 встаёт на свободный `sort_order` 0, поэтому они не конфликтуют,
  но в списке будет два урока с одним названием.
* Включить публикацию: оба урока заливаются с `is_published = false`.

## План урока и презентация

| файл | что это |
|---|---|
| `plan.py` → `Unit 0 Lesson 6.docx` | план урока «Lesson 6 (Revision + Test)» по формату действующих планов SM0 |
| `deck.py` → `Unit 0 Lesson 6.pptx` | презентация к нему, 31 слайд, с двумя играми внутри |

Пересобрать: `python3.13 builds/sm0/u0/plan.py "builds/sm0/u0/Unit 0 Lesson 6.docx"`
и `python3.13 builds/sm0/u0/deck.py "builds/sm0/u0/template_Unit 1 Lesson 7.pptx" /tmp/png "builds/sm0/u0/Unit 0 Lesson 6.pptx"`
(папку png скрипт создаёт сам из `media/sm0/legacy`).

Презентация собирается на шаблоне `template_Unit 1 Lesson 7.pptx` (прислан
методистом): скрипт открывает его, удаляет слайды и строит свои в том же
оформлении — фоны FFE4EA / E3F0FB, белые круги по углам, белая карточка,
Verdana и Trebuchet MS. На слайдах только английский, короткой строкой
(«Click the colour!»); русский — в плане урока и на слайде «Я могу!».

Игры собраны переходами по клику, без Wordwall:
* **«Поймай цвет»** — шесть шариков, клик открывает название цвета и
  возвращает на поле; дальше три круга «How many?» со счётом шариков;
* **«Кубик и чтение»** — кубик идёт по кругу 1→6, на каждом слайде слово
  крупно: sat · pin · ten · red · kit · dad.
