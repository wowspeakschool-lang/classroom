# SM0 · Unit 0 — что здесь лежит

Ничего из этого **не залито** в базу: Classroom переезжает на WowSpeak Team,
до переезда заливка запрещена. Файлы собраны так, чтобы их можно было достать
и перенести в любой момент, в том числе из другой сессии.

| файл | что это |
|---|---|
| `build.py` | сборка: держит содержимое уроков и выдаёт SQL и JSON |
| `u0_hw1.sql` · `u0_hw1.json` | **Homework 1** юнита 0, собрана по плану «Lesson 1 (Hello)». В базе её не было: на её месте лежит копия Homework 4 юнита 1 |
| `u0_test.sql` · `u0_test.json` | **тест юнита 0** к уроку Lesson 6 «Revision + Test» |
| `u0_test_sostav.md` (папкой выше) | состав теста человеческим языком |

SQL — для текущей схемы (`classroom_lessons` / `classroom_blocks`), запускается
в SQL Editor целиком, идемпотентен: повторный запуск перезапишет блоки, а не
удвоит их. JSON — то же содержимое без привязки к схеме: если на WowSpeak Team
таблицы окажутся другими, уроки собираются из него.

Пересобрать после правок: `python3.13 builds/sm0/u0/build.py`
Проверить перед заливкой: `python3.13 tools/val.py builds/sm0/u0 sm0/legacy`

  юнита 0 весь звук записан её голосом, а не синтезом.
