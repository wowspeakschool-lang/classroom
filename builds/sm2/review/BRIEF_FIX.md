## 4. Объём домашки — главная содержательная работа

**Ориентир — 8 заданий в домашке, нижняя граница 6.** Задание — это блок
любого типа, кроме `text` и `video`.

Посчитать свои домашки:
```sql
select l.sort_order+1 as hw, count(*) as blocks,
  count(*) filter (where b.type not in ('text','video')) as tasks
from classroom_courses c
join classroom_units u on u.course_id=c.id
join classroom_lessons l on l.unit_id=u.id
join classroom_blocks b on b.lesson_id=l.id
where c.slug='sm2' and u.sort_order=<N> and l.kind='homework'

```

**Как добирать — требование методиста:** не мелкими блоками по одному пункту,

предложение, а четыре. «Впиши слово» — 5–6 пунктов. «Верно/неверно» — 5–6
утверждений. «Разложи по корзинам» — не меньше 8 карточек.

**Откуда брать содержание:** только из материала этого же урока — его лексика,
его грамматика, его история, его картинки (смотри, что лежит в
`/home/user/classroom/media/sm2/u<N>/` и что уже используется в уроке).
Ничего нового не вводить. Если материала не хватает даже на шесть заданий —
так и напиши в отчёте, не выдумывай.

**Если в домашке больше 20 блоков** — посмотри, нет ли там отдельных текстовых
блоков с одной картинкой перед заданием. У `order`, `gaps`, `quiz`, `task`,
`exact_input` есть собственное поле `image` — перенеси картинку туда, пустой
текстовый блок удали.

## 6. Как писать миграции

- Путь к картинке собирать через плейсхолдер и `replace(..., '@@MEDIA@@', v_media)`,
  как в CLAUDE.md. **Никогда не вставлять base64.**
- Вставка блока в середину урока — сдвиг через +1000, иначе уникальный ключ
  `(lesson_id, sort_order)` поймает на лету:
  ```sql
  update classroom_blocks set sort_order = sort_order + 1000
    where lesson_id = v_lesson and sort_order >= <поз>;
  update classroom_blocks set sort_order = sort_order - 999
    where lesson_id = v_lesson and sort_order >= 1000;
  insert into classroom_blocks (lesson_id, type, payload, sort_order) values (...);
  ```
  (при вставке двух блоков — `- 998`, и так далее).
- **`delete` через MCP зависает** — инструмент считает его разрушающим.
  Если нужно удалить блок: завести функцию `create or replace function ...`
  с `delete` внутри и вызвать её обычным `select`. После — обезвредить
  функцию, заменив тело на `select 0`.
- Разметка озвучки: рядом с пустым `audio` ключ `audio_tts` (строка или
  `{text, voice}`). Звук методист включает сама, нам его не ставить.

## 7. Проверка после каждой миграции — обязательно

```sql
select count(*) as blocks,
  count(*) filter (where dup) as dup_sort, count(*) filter (where gap) as gaps
from (
  select b.id,
    count(*) over (partition by b.lesson_id, b.sort_order) > 1 as dup,
    false as gap
  from classroom_blocks b
  join classroom_lessons l on l.id=b.lesson_id
  join classroom_units u on u.id=l.unit_id
  join classroom_courses c on c.id=u.course_id
  where c.slug='sm2' and u.sort_order=<N>) x;
```

И отдельно глазами:
- в каждом уроке нумерация без пропусков (`max(sort_order) = count(*) - 1`);
- **прощание осталось последним блоком** в каждой домашке;
- в `order` склейка `words` равна `sentence`;
- в `match` правые значения уникальны;
- у `quiz` с `type: single` ровно один верный ответ;
- ни одного оставшегося `@@MEDIA@@`.
