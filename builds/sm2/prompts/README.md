по горькому опыту: картинки Unit 4 пропали вместе с контейнером той сессии
(в `media/sm2/u4/` остались только 20 из выгрузки, а 25 сгенерированных — нет,
и в истории git их нет вообще). Файлы картинок восстановить уже нельзя, промпты
— можно, если они лежат здесь.

и промпты, которыми они сделаны.
