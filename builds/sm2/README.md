# builds/sm2 — сборки уроков Super Minds 2

По файлу на юнит: блоки на питоне → миграция SQL. Запускать из этой папки,
SQL ляжет в `uNsql/` рядом (папки в репозиторий не коммитятся):

```bash
cd builds/sm2
python3 u6_build.py                                  # → u6sql/*.sql
python3 ../../tools/val.py u6sql sm2/u6              # должно быть «ОШИБОК: 0»
```

Дальше каждый файл — отдельный `apply_migration`. Миграции идемпотентны: ключ
`(lesson_id, sort_order)` и `delete … where sort_order >= N` в конце, так что
повторная заливка переписывает урок целиком, а не плодит блоки.

Правка уже залитого урока идёт здесь, а не прямо в базе: это единственное место,
где видно урок целиком. Точечные правки (вписать ссылку на медиа) допустимы
обновлением payload, но тогда ту же правку надо внести и в сборку — иначе
следующая полная заливка её затрёт.

Описание конвейера целиком — `tools/README.md`.
