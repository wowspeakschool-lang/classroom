# Аудирования тестов GG2 — расшифровки и сверка ключей

Записи — **оригиналы комплекта Go Getter 2**, Анна скачала и залила их 19.10.2026.
Решение от 22.10 и повторно 05.11.2026: **не трогаем** — там живые разные голоса,
заменять их синтезом одним голосом SpeechKit нельзя.

С 22.10 висел открытый вопрос: текстов записей нет, и **десять ключей нечем
сверить**. 05.11.2026 закрыт: девять доступных записей скачаны из бакета и
расшифрованы (faster-whisper `small.en`, mp3 → wav 16 кГц моно через ffmpeg).
Расшифровки — `rasshifrovki.json`.

**Результат сверки: все девять ключей верные.** Проверено по каждому пункту:

| юнит | тип | что сверено | итог |
|---|---|---|---|
| 0 | sort | шесть фактов по трём подросткам (Tom · Léa · Aylin) | верно |
| 1 | sequence | семь событий вторника Софии, порядок | верно |
| 2 | truefalse | пять утверждений (мама, не папа; рис, не паста) | верно |
| 3 | quiz T/F/NS | семь утверждений, включая «не сказано» про возраст брата | верно |
| 5 | sequence | шесть мест по дороге к отелю, порядок | верно |
| 6 | sort | восемь фактов по четырём говорящим | верно |
| 7 | quiz | Edinburgh · return · Sunday evening · 11:30 · £85 · platform 6 | верно |
| 8 | sequence | шесть реплик Бена, порядок | верно |
| 9 (Final) | truefalse | шесть утверждений (Emma, не Tom; на автобусе, не пешком) | верно |

**Про новое правило аудирования** (несколько героев, все варианты звучат):
семь записей ему и так отвечают — это диалоги, рассказы нескольких человек и
задания на порядок, где звучит каждый пункт. Исключение — юнит 7: там варианты
£55 / £75 / £95 и платформы 4 / 5 / 16 в записи не произносятся. Это дефект по
новому правилу, но исправлять его значит переписывать оригинальную запись, и
05.11 Анна решила GG2 не трогать.

**Юнит 4 — единственный, где записи нет вовсе.** Решение Анны 05.11.2026:
писать свой текст на озвучку. Текст — `u4_tekst.md`, он же в сообщении для чата
озвучки. Варианты ответов менять не пришлось: текст написан так, что все четыре
варианта каждого вопроса в нём звучат.
