   «black dog», «blue». Не команды («Circle two cats!», «Colour the dog black!»,

3. **Задания на звук** (/b/, /d/, /t/, /s/, /p/, /ʃ/): без звука-подсказки у

5. **«Что пропало?» в домашках не делаем** — заменить своим заданием на слух

8. **Раскраски убираем** (решение Анны 16.10): «Послушай и раскрась» в домашке не делаем —

## Как писать в базу

1. **Перед правкой блока — прочитай его текущий payload по `id`.** Правишь по
   `id`, никогда по `sort_order`.
2. Одна правка — один `update`:
   ```sql
   update classroom_blocks set type='quiz', payload=$j${...}$j$::jsonb where id='<uuid>';
   ```
   Payload пиши целиком, полностью сохраняя то, что не меняешь (картинки,
   поля, `needs_review`). Строки JSON — без переносов внутри.
3. **Новый блок**: `insert into classroom_blocks (lesson_id, type, payload,
   sort_order, audience, variant, format) values (…, 'shared', 'any', 'any')`.
   Уникальный ключ `(lesson_id, sort_order)`: если места между соседями нет —
   сначала сдвинь хвост урока (`update … set sort_order = sort_order + 100
   where lesson_id = … and sort_order > N`), потом вставь. Прощание должно
   остаться последним.
4. **Удалять блоки** — только если без этого никак (дубль, лишний блок в
   тесте). Если `delete` не проходит, не обходи: перечисли id в ответе.
5. После правок урока — **контрольный запрос** (см. ниже). Ошибка — чини сразу.

## Звук

- Всё, что ребёнок должен услышать, — ключ `*_tts` рядом с полем звука:
  `audio_tts` у вопроса и варианта, `right_audio_tts` / `left_audio_tts` в
  `match`, `sample_tts` в `speaking`, `audio_tts` у блока `sequence` (чант
  целиком), `audio_tts` у элементов `sort`, `sequence`, `flashcards`.
  Значение — строка с английским текстом.
- **Если меняешь текст звука, поле самого звука делай пустым** (`"audio": ""`,
  `"sample": ""`). Иначе останется старая запись, а «Озвучить пачкой» не
  перезапишет заполненное поле.
- **Решение Анны: никаких английских вопросов-фраз в озвучке** («What is
  blue?», «Who is cute?», «Which one is different?» — нельзя). Задание
  ставится по-русски («Послушай и выбери»), а в озвучке вопроса — **одно
  ключевое слово**: «blue», «cute», «fly». Русская инструкция при этом ответ не
  называет («Послушай и выбери», а не «Выбери всё синее»).
- В «лишнем» звука у вопроса нет совсем: инструкция по-русски «Какая картинка
  лишняя?», а слово звучит у каждого варианта.
- Фразы, которые ребёнок учил на уроке («I like pizza!», «Is it a car?», «It's
  sunny»), остаются фразами — правило выше только про вопросы-обёртки.

## Контрольный запрос после каждого урока

```sql
select row_number() over (order by b.sort_order) n, b.type,
  b.payload::text like '%data:image%' b64,
  (select count(*) from jsonb_array_elements(coalesce(b.payload->'questions','[]')) q,
     jsonb_array_elements_text(q->'correct') c
   where c::int >= jsonb_array_length(q->'options')) bad_correct
from classroom_blocks b join classroom_lessons l on l.id=b.lesson_id
join classroom_units u on u.id=l.unit_id join classroom_courses c on c.id=u.course_id
where c.slug='wow-dragon-1' and l.title='Homework N' order by b.sort_order;
```

Плюс проверь глазами: `multiple` — верных ≥ 2, `single` — ровно 1; нет
одинаковых вариантов в вопросе; правые значения `match` уникальны; первый блок —
приветствие, последний — прощание; все ссылки на картинки есть в `media/`.
