## Режим «ученик не читает» — главный в этой вычитке

- **Вариант ответа словом — находка.** Вариант `quiz` без картинки
  показывается текстом (`index.html`, рендер `quiz`): ребёнок его не прочтёт.
  Нужна картинка, а если задание на слух — звук у варианта.
- **Задание на чтение английского — находка.** Исключение: уроки, где
  проверяются выученные буквы. Там буква на экране — это и есть материал.
- **Звук везде, где он нужен** — слово это или фраза, неважно. Ребёнок
  должен услышать каждое английское слово, которое ему надо узнать или
  выбрать. Пустой `audio` при наличии разметки `*_tts` — не находка агента
  (это «Озвучить пачкой», считается запросом); **отсутствие и звука, и
  разметки там, где звук нужен — находка**.
- **«Послушай и выбери» без звука в вопросе** — задание нерешаемо.
- **Озвучка не должна выдавать ответ** там, где задание проверяет не слух
  (например, вопрос «что лишнее?» с озвученным правильным вариантом).
- **Инструкция по-русски** читается взрослым или ребёнком — это нормально.
  Но смысл задания должен быть понятен и без чтения: из картинки, звука,
  образца. Инструкция короткая, понятная пятилетнему.
- **Варианты в `quiz` не перемешиваются** — позиция верного ответа видна.
  Это проверено запросом (`00_centralized.md`), агент это не пересчитывает,
  но если в конкретном вопросе ответ угадывается по позиции или по тому, что
  картинка одна цветная среди серых — это находка слоя 4.

## Типы блоков в курсе

`quiz` (`questions[].q, type single|multiple, correct[], options[{text, image,
audio}], audio, image`), `speaking` (`title, html, image, sample`), `text`
(приветствие и прощание), `sort` (`groups[{name, items[{text, image,
audio}]}]`), `match` (`pairs[{left, left_image, right, right_image,
right_audio}]`), `flashcards` (`cards[{text, translation, image, audio}]`),
`sequence` (`items[]` — **порядок в массиве и есть ответ**). Рядом с полем
звука может лежать `*_tts` — текст, который синтезируется. Звук ты не
слышишь; что в нём, суди по `*_tts`. Если звук есть, а `*_tts` нет —
содержимое неизвестно, находкой это не считай.

## Где брать данные

**Блоки домашки** — `mcp__Supabase__execute_sql`, проект `vtcxghsqymwkyiogpndf`,
только `select`:

```sql
select row_number() over (order by b.sort_order) as block_no, b.type, b.payload
from classroom_courses c
join classroom_units u on u.course_id = c.id
join classroom_lessons l on l.unit_id = u.id
join classroom_blocks b on b.lesson_id = l.id
where c.slug = 'wow-dragon-1' and l.title = 'Homework 12'
order by b.sort_order;
```

**Номер блока в отчёте — `block_no` из этого запроса** (порядковый, как в
редакторе), а **не** `sort_order + 1`: в Wow Dragon нумерация в базе с дырами.

**Картинки** открывать глазами (Read). Ссылка
`https://classroom.wowteach.ru/media/<путь>` = файл
`/home/user/classroom/media/<путь>`. Спорную картинку смотреть, а не судить
по имени — имена тут md5, по ним ничего не понять.

**План урока** — `mcp__Google_Drive__search_files` с `parentId = '<id папки>'`
(не поиском по названию), затем `mcp__Google_Drive__read_file_content` для
`.docx`. В начале плана — Topic, Aims (лексика, фразы, буквы), дальше этапы.
Программа курса до текущего урока — `docs/vychitka/wd1/syllabus.md`.

## Слои — что ищет агент

Как в `tools/vychitka.md`, раздел 3, с поправками:

1. Механика — не делать, это `00_centralized.md`.
2. **Английский** — в `*_tts`, словах вариантов, `sample`. Фразы короткие и
   естественные для дошкольника.
3. **Инструкции** — понятны пятилетнему, одинаковые для однотипных заданий,
   на «ты», **описывают то, что блок делает** («соедини» у `quiz` — находка).
4. **Логика** — верный ответ верен; второго верного нет; решаемо из данного;
   **нельзя решить в обход языка** (по позиции, по единственной цветной
   картинке, по озвучке ответа); для `multiple` — отмечены все верные.
5. **Картинки** — относятся к вопросу, не выдают и не противоречат ответу;
   один предмет — одна картинка на всю домашку (не «кошка» двумя разными
   рисунками). Кастомных персонажей не трогать.
6. **Соответствие изученному** — слова и фразы не выходят за программу
   **до этого урока включительно**. Что появляется впервые — выписать.
   Что урок дал (Aims), а домашка не закрепила — находка.
7. **Сложность** — ровная; у однотипных вопросов одинаковое число вариантов;
   домашка не из одного типа блока.
8. **Объём** — ориентир 8 заданий с подзаданиями; домашка короче — назвать
   и предложить, чем дополнить из материала того же урока. Нет `speaking` —
   предложить готовое устное задание.
9. **Идеи** — не больше двух на домашку, конкретно.
