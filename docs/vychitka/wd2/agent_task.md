# Вычитка и правка WD2 — задание агенту диапазона

Ты вычитываешь И СРАЗУ ПРАВИШЬ домашки своего диапазона прямо в базе
(`mcp__Supabase__execute_sql`, проект `vtcxghsqymwkyiogpndf`). Решения Анны по
первой части уже известны — по ним правишь без вопросов. Спрашиваешь только
то, что под них не подпадает.

Прочитай по порядку:
1. `docs/vychitka/wd2/brief.md` — главное: курс в базе, 16 решений Анны.
2. `docs/vychitka/wd1/brief.md` — анкета, режим «ученик не читает», слои 2–9.
3. `docs/vychitka/wd1/fix_brief.md` — как писать в базу, звук, картинки, тексты,
   контрольный запрос (для WD2 фильтр `u.course_id='2b4c8528-ae7e-4e97-bfca-c34ac2ed4efa'`
   вместо slug).
4. `docs/vychitka/wd2/syllabus.md` — программа; английский только до текущего
   урока включительно (плюс всё из Wow Dragon 1, `docs/vychitka/wd1/syllabus.md`).
5. `docs/vychitka/wd2/media_inventory.md` — комиксы, аудио, песни на Диске.

## Порядок по каждой домашке
1. Прочитай все блоки (`id`, тип, payload). Картинки, по которым неясно, —
   открой Read (`/home/user/classroom/media/<путь после /media/>`).
2. Найди проблемы по слоям 2–9 и по решениям Анны.
3. Исправь всё, что покрывается решениями Анны и правилами fix_brief. Правка —
   по `id`, payload целиком с сохранением прочего или точечно `jsonb_set`.
   Без `;` внутри SQL-строк (MCP виснет) — `replace(..., '~', chr(59))`.
   Блоки не удалять. Новый блок — только если без него домашка короче
   8 заданий или нет устного (`speaking`); вставка по правилам fix_brief.
4. **Комиксы, аудио комиксов, кастомные песни школы — не трогать** (блок
   целиком). Если звук/картинки там нет или стоит не то — строка
   «Вставить с Диска».
5. Контрольный запрос и проверки после каждой домашки.

## Ответ — текстом (файлы не писать)
1. По каждой ДЗ 2–5 строк: что исправлено (номера блоков как в редакторе).
2. **Не сделано** и почему.
3. **Вопросы Анне** — только новое, с вариантами и твоей рекомендацией.
4. **Нужна картинка**: ДЗ · блок · что нарисовать (для промптов).
5. **Записать голосом** (буквы): ДЗ · блок · буквы.
6. **Вставить с Диска** (комиксы, аудио комиксов, песни): ДЗ · блок · файл
   (имя, fileId из media_inventory) · куда.
