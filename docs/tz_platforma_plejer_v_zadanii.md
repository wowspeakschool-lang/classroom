**Плеер записи внутри задания — проверить по всем типам блоков**

Что изменилось у нас в контенте. По решению методиста запись (аудирование)
больше не лежит отдельным блоком перед заданием: раньше ученик видел блок с
одним плеером, а под ним отдельную рамку с вопросами, и плеер «уезжал» в соседние
блоки при прокрутке — преподаватели принимали это за ошибку. Теперь ссылка на
запись стоит в `payload.audio` **самого задания**, а блок-плеер убран. В домашках
сведено по всем курсам (37 мест, 02.11.2026), в тестах — ещё девять мест
(03.11.2026). Где одна запись нужна двум заданиям подряд, она стоит в обоих.

Что просим проверить: что блок **любого типа** с непустым `audio` в payload
показывает плеер над заданием. Сейчас так размечено 272 блока:

| тип блока | блоков с `audio` |
|---|---|
| sequence | 78 |
| quiz | 43 |
| order | 37 |
| speaking | 24 |
| gaps | 23 |
| text | 21 |
| match | 12 |
| hotspot | 11 |
| sort | 8 |
| truefalse | 8 |
| task | 7 |

Сами видели плеер у `hotspot` — SM1 Final Test, задание 2. Остальные типы
проверить, и если у какого-то плеера нет, добавить тот же плеер, что у `text`
и `quiz`, над материалом задания. Запись берётся с уровня блока
(`payload.audio`), не с уровня вопроса.

Где посмотреть (все уроки — черновики, `is_published = false`):

| тип | где |
|---|---|
| sort | GG2 Unit 0 Test блок 12 · GG2 Unit 6 Test блок 12 |
| truefalse | GG2 Final Test блок 7 · GG3 Final Test блок 3 |
| match | SM3 Final Test блок 4 |
| hotspot | SM3 Final Test блок 3 |
| sequence | GG2 Unit 8 Test блок 12 |
| quiz | GG2 Unit 7 Test блок 12 |
| gaps | SM1 Unit 8 Test блок 11 |

Номера блоков — как в редакторе.
