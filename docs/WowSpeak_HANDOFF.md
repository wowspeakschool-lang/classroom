## 1. Что это за проект

Бесплатный лид-магнит для онлайн-школы английского WowSpeak: мини-курс из **4 самодостаточных HTML-уроков** (по одному файлу на урок). Ребёнок учит английский через игру. Цель курса — довести ребёнка до записи на бесплатный вводный урок (в финале Урока 4 есть кнопка записи для родителей).

**Педагогика по урокам:**
- **Урок 1** — лексика одежды (a cap, a T-shirt, jeans, a skirt, a jacket, shoes, socks).
- **Урок 2** — грамматика «I have got / I haven't got».
- **Урок 3** — «he/she has got / hasn't got» (герои Бен и Мия).
- **Урок 4** — проект: ребёнок собирает своего аватара и описывает его; финал курса.

**Система наград (рюкзак, накапливается сквозь уроки):**
кристалл + палочка (У1) → меч (У2) → медаль (У3) → корона + дракон (У4). 6 слотов, к финалу 6/6.

**Ключевые ограничения:**
- Claude **не генерирует картинки**. Все изображения генерирует Анна (владелец) по промптам и присылает; ассистент собирает их в HTML (base64).
- **Нет видео.** Звук — через Web Speech API (робот-TTS); позже заменяется на записанное аудио Анны (см. §7).
- Всё в одном self-contained HTML-файле на урок (картинки встроены base64).

## 3. Техническая архитектура уроков

Каждый урок — один HTML-файл: `<style>…</style>` + один большой `<script>…</script>`. Внутри скрипта:

- **`IMG` / ассеты** — объект с base64-картинками (одежда, награды, герои, фоны). Это основной вес файлов.
- **`screens`** — массив объектов-экранов. У каждого: `id` (напр. `"5-1"`), `type`, `speech` (реплика гида в intro-фазе), `buttonLabel`, `instruction`, данные задания (`rounds`, `questions`, `pairs`, `phrases`, `options` и т.п.), иногда `singlePhase: true`.
- **`linearOrder`** — массив id в порядке прохождения. Именно он определяет последовательность (не порядок в `screens`).
- **`contentRenderers`** — объект `{ типЗадания: function(s, root){…} }`. Рендерит контент-фазу экрана.
- **Фазы экрана:** большинство экранов = intro-фаза (гид говорит `speech` + кнопка `buttonLabel`) → `advancePhase()` → контент-фаза (`contentRenderers[type]`). Экраны с `singlePhase:true` (greeting, achievement, backpack, farewell) рендерятся сразу.
- **`state` + `localStorage`** — прогресс внутри урока (текущий экран, ответы, `projectText`, `avatarGender` и т.п.), функция `saveState()`.
- **`speakEN(text, btn, onDone, voiceKind)`** — озвучка. `voiceKind`: `"f"` = женский голос (учитель/Мия), `"m"` = мужской (Бен). Использует `femaleVoice`/`maleVoice`/`englishVoice` (единый движок во всех 4 уроках).
- **`SFX`** — звуки (correct/wrong/complete) через WebAudio.
- **`el(tag, attrs, child)`** — хелпер создания DOM.
- **`next()`** — переход к следующему экрану по `linearOrder` (или по `s.next`).
- **`DEV`** — флаг dev-навигации (стрелки). Во всех публикуемых = `false`; в Уроке 1 флага нет вовсе (dev-панели там не было).

### Два «фреймворка» — ВАЖНО
- **Урок 1** — старая схема. Формат `id: "1-1"` (с пробелом после `:`), `type: "memory"` (с пробелом). Свои рендереры.
- **Уроки 2/3/4** — «L2-фреймворк». Формат `id:"1-1"` (без пробела). Общие хелперы: `l2Continue()` (создаёт sticky-кнопку «Дальше»), `l2Finish(section, cont, doneMsg)`, `l2Shuffle(n)`, `l2ItemChip()`, `l2OptionsQuestion(container, question, options, correctIdx, onSolved)`. Задания-очереди используют `ri` (round index) + `show()`/`showRound()` над `s.rounds`.

### Извлечение рендерера из файла (для правок)
Рендереры — методы объекта. Ищутся по `имя: function(s` (У2-4) или `имя: function(s` с пробелами (У1), затем сопоставлением скобок `{…}`. Правки делаются точечной заменой строк (Python string replace) прямо в HTML, потом обязательная валидация (см. §8).

- **У2:** greeting, leadin, discovery, fragmentgame, choosehg, readchoose, baskets, buildphrase, fillgap, **speaking** (нов.), achievement, backpack, reflection, farewell.

## 4. Что уже реализовано и провалидировано

Всё ниже сделано в предыдущих сессиях, работает, файлы валидны (0 ошибок, 0 переполнений на 320/390/768/1280 px):

1. **Консистентность:** правильный `<title>` у каждого урока; единый speak-движок (голоса + `voiceKind`) во всех уроках. Учитель по имени НЕ представляется (решение Анны).
2. **Финал Урока 4:** экран показа родителю (`parentshow`, галочка-гейт), дракон, рюкзак 6/6, рефлексия, прощание. Оверлей «Курс WowSpeak завершён!».
3. **Кнопка записи родителей** в финальном оверлее У4: карточка «Для родителей» + кнопка «Записаться на вводный урок». Ссылка — в константе `const SIGNUP_URL = "";` (рядом с `DEV`, пустая, Анна вставит позже; пока показывает alert «Ссылка появится скоро»).
4. **Подсказки при ошибках** в заданиях с вариантами: 1-я ошибка — тряска; со 2-й ошибки убирается по одному неверному варианту (класс `.eliminated`), пока не останется правильный (без зелёной подсветки). Реализовано во всех уроках.
5. **Возврат слова с ошибкой в конец очереди** (один раз, экран «Повторим ещё раз 🔁») — во всех раундовых заданиях. Механика: локальная `queue = s.rounds.slice()` + `requeue(r)` с флагом `r._isRepeat`.
6. **«Найди пары» (У1 memory):** в начале все карты открываются на 5 сек с отсчётом «👀 Запомни, где что! 5…», потом закрываются. Подсказок нет. Озвучивается ТОЛЬКО карточка со словом (картинка молчит).
7. **«Соедини пары» (У3 matchpairs, У4 matchpics):** подсказки убраны (карты и так открыты).
8. **«Послушай и повтори» (speaking):** новый экран в У2 (id `4-4`, после discovery, перед играми) и У3 (id `4-5`). 4 фразы, крупная 🔊 (авто-озвучка + повтор), «🔁 Повтори вслух!», в конце «К играм!». Урок 1 уже имел это в презентации (оставлено). Урок 4 — не нужно (там повторение + проект).
9. **«Почини фразу» (У3 fixphrase):** интерактивная подсказка-правило. При 2 ошибках ввода всплывает окно «He — have или has?» с двумя кнопками; выбор верного → «✅ Верно! He → has. Замени «have» на «has».» + «Понятно». Классы `.fix-rule-*`.
10. **Пример нельзя копировать** (`.fp-example { user-select:none; -webkit-touch-callout:none }`) во всех заданиях с вписыванием.
11. **Кнопки «Проверить/Готово/Дальше» всегда на виду:** sticky (`.continue-area` и `.l2-sticky` → `position:sticky; bottom:12px`). Причина прошлых багов: `body{overflow-x:hidden}` ломает sticky → заменено на `overflow-x:clip`. Отключённая кнопка = `.disabled-look { pointer-events:none }` (не блокирует контент под собой) + сплошной светлый фон `#e7e2f3` (была прозрачная `opacity:0.5`).
12. **Рюкзак адаптивен:** `.shadows-grid` = `repeat(6, minmax(0,1fr))`, `.shadow-slot` резиновый (`width:100%; max-width:56px; aspect-ratio:1`). Раньше 6 фикс-слотов «ехали» на телефоне.
13. **Рефлексия** («что сложно / что понравилось»): кнопка «Далее» заблокирована, пока не выбран хотя бы 1 вариант (во всех уроках; в У1 это чинилось отдельно).
14. **Ввод в «Посмотри и впиши» (У2 fillgap, id `5-5`):** настоящее поле `<input class="fill-input">` (на телефоне открывается системная клавиатура), плюс экранная клавиатура по кнопке «⌨️ Экранная клавиатура» (скрыта по умолчанию, вписывает в то же поле). Автозамена/автозаглавные отключены.

**Адаптивность:** во всех 4 уроках есть `<meta viewport>`, вёрстка резиновая. Проверено на 320/360/390/768/834/1024/1280/1440 — чисто. Тап = клик (мышь и палец работают одинаково).

## 5. НОВАЯ ЗАДАЧА (обсуждается, ещё НЕ реализована): «Карта Волшебной страны»

Анна хочет обернуть 4 урока в **сквозной сюжет-приключение с картой-хабом**. Ярче, красочнее, с историей.

### Утверждённые решения:
- **Объём:** гибрид. Задания и учебный материал ОСТАЮТСЯ; меняем визуал (фоны, стиль), сюжетные вставки, тематику островов; картинки одежды и награды НЕ трогаем. Отдельные задания можно точечно «переодеть» под остров (по желанию).
- **Главная цель-сбор:** **собрать 4 части карты**. Каждый остров даёт 1 часть. Собрал 4/4 → карта целая → открывается путь к Замку → просыпается дракон (финальная награда, уже есть).
- **Гид:** учительница-женщина (как сейчас), в роли проводника по карте.
- **Структура:** отдельный лёгкий файл-**карта** (хаб) + 4 файла-урока. Общий прогресс.
- **Формат файлов:** не строго один файл — карта + 4 урока ок. Главное: виден переход между уроками и прогресс сохраняется.

### Механика прогресса (важно технически):
- Карта и уроки шарят `localStorage` — **работает только если все файлы на одном домене/origin**. Предложенный ключ: `wowspeak_journey = { island1: true, island2: false, ... }` (или массив собранных частей).
- Карта читает прогресс, показывает пройденные острова (светятся, часть карты появляется), открывает следующий остров, планка «Части карты: N из 4».
- Урок на выходе пишет `island{N}=true` и показывает «получил часть карты 🗺️» + кнопку «Вернуться на карту» (ссылка на файл-карту).
- Замок открывается при 4/4 → кнопка «В Замок!» → финал/дракон (в Уроке 4).

### Острова (магические названия под нашу грамматику):
| Остров | Урок | Сюжет | Вход (реплика гида) | Выход |
|---|---|---|---|---|

| 2. Остров Зеркал | У2 I have got | Зеркала показывают, что есть у ТЕБЯ | «Волшебные зеркала покажут, что есть у тебя. Научись говорить „I have got“.» | «Получил меч ⚔️! Вот 2-я часть карты.» |
| 3. Остров Друзей | У3 he/she has got | Знакомишься с Беном и Мией | «Здесь живут Бен и Мия. Расскажи про них — „he/she has got“.» | «Получил медаль 🏅! Вот 3-я часть карты.» |

## 8. Рабочий процесс и валидация (как править и проверять)

- **Правки:** точечная замена строк в HTML (найти рендерер сопоставлением скобок, заменить). Всегда сверять точный текст перед заменой.
- **Проверка синтаксиса:** извлечь `<script>` в `.js` → `node --check`.
- **Функциональная валидация:** Playwright (headless Chromium). Паттерн: `localStorage.clear()` → `reload` → `goTo("id")` → `advancePhase()` → проверки DOM/скриншоты. Обход всех экранов из `linearOrder`, проверка переполнения (`scrollWidth - clientWidth > 2`) и `pageerror`/console-error на ширинах 320/390/768/1280.
- **Гид/озвучка:** `speakEN(text, btn, onDone, voiceKind)` — не забывать `voiceKind` для мужских реплик (Бен = "m").
- **Готча:** контейнер иногда сбрасывается — рабочие файлы восстанавливать из outputs (`cp /mnt/user-data/outputs/Урок_N.html uN.html`). Всегда пересохранять правки обратно в outputs.
- **Скриншоты** для показа — full_page или viewport; учитывать, что скриншот может «поймать» момент анимации/переворота карт.

## 9. Стиль и принципы (важно держать)

- Инструкции для ребёнка — **на русском**; целевая лексика (одежда) и фразы — на английском.
- Анна итеративна, часто меняет решения по ходу и просматривает экран за экраном. Принимать «стоп» и правки спокойно. Для лид-магнита: **проще = лучше**.
- Подсказки ПОМОГАЮТ найти ответ в квизах (исключение вариантов) и в «Почини фразу» (правило), но их НЕТ в играх на запоминание (там показ карт на 5 сек заменяет подсказку).
- Тон дружелюбный, детский, ободряющий. Кнопки/награды/темп — единообразны между уроками.
- Дизайн-цвета: основной фиолетовый `--primary: #3D2E68`; акцент оранжевый `#e08a2b`; фоны светло-сиреневые (`#f6f4fc`, `#e7e2f3`); зелёный успех `#4caf50`.

## 10. Быстрый старт для Claude Code

1. Положить `Урок_1..4.html` в репозиторий.
2. Для любой правки урока: открыть файл, найти нужный рендерер/экран, править точечно, проверить `node --check` на извлечённом скрипте, прогнать Playwright-обход по `linearOrder`.
3. Для карты: начать с §5 (концепция утверждена) → закрыть §6 (реплики, названия) → написать промпты картинок для Анны → собрать файл-карту + механику `wowspeak_journey` в localStorage + входы/выходы в уроках.
4. Помнить: картинки генерирует Анна, ассистент даёт промпты и собирает.
