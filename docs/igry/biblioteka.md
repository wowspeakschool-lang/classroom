# Библиотека игр интерактивных уроков

Заведена по просьбе Анны 27.11.2026: какие режимы игр мы уже делали, где лежит код и как их
собрать снова. Пополнять после каждого урока. Уроки — однофайловые HTML, сборщики — Python
(шаблон + данные), картинки — по ссылкам `classroom.wowteach.ru/media/…`.

Где код:
- Halloween 4–6, 7–9: готовые уроки `lessons/halloween/4-6.html`, `7-9_*.html`. Исходные шаблоны
  (`template.html`, `template7.html`) жили в скретчпаде и потеряны вместе с контейнером — код игр
  берём из готовых уроков. **Шаблоны и сборщики новых уроков сразу коммитим в `builds/newyear/`.**
- Halloween 10–12: `build10.py` → `lessons/halloween/10-12_*.html`.
- Halloween 13+: `build13.py` → `lessons/halloween/13plus_*.html`.
- Внешние ресурсы, предзагрузка, кнопки скачивания плана — `builds/halloween/externalize.py`.
Номер экрана (`id="…"`) в таблице — чтобы найти разметку и скрипт игры в готовом уроке.

Общие правила, вынесенные из Halloween: озвучки слов нет (говорит учитель); ничего не листается и
не двигается само; где читают — кнопка Next; прогресс — кружочками; под фонариком видна сцена;
у решения «верно/неверно» есть «I don't know»; картинки для canvas — с `crossOrigin='anonymous'`.

## Новые режимы (задуманы для New Year, 27.11.2026)
- **Поймай** (идея Анны): внизу персонаж с мешком/корзинкой, водят мышкой или пальцем, сверху падает;
  ловим то, что назвал учитель. Работает на телефоне (pointer events, без клавиш).
- **Пары**: карточки рубашкой вверх, у одной нет пары — она остаётся в конце и становится героем сюжета.
- **Создай снеговика (конструктор)**: основа + детали без фона в одном масштабе, у каждой детали точка
  крепления в пикселях основы; отпущенная рядом — встаёт точно, иначе возвращается. Проверка скриншотами.
- **Найди отличия слоями**: картинку собираем из фона и отдельных предметов; второй вариант — те же слои
  без нескольких предметов. Отличия ровно те, что нужно, остальное совпадает до пикселя.
- **Снежки (крот)**: из сугробов выглядывают картинки, бросаем снежок в названную.
- **Волшебные шары**: шар на ёлке раскрывается, внутри картинка.
- **Из тумана (размытие)**: картинка проступает из размытой.
- **Найди на картинке** (на будущее, для старших): слева большая сцена, справа список картинок того,
  что надо найти; найденное отмечается.
