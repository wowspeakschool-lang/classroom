# Макеты

Согласованная натура для оставшейся работы по визуалу, не черновики.
Открывать файлом в браузере, они самостоятельные.

| файл | что показывает |
|---|---|
| `uchenik_3varianta.html` | ученический вид, три темы — **тёплая утверждена** — эффекты, режим чтения |
| `classroom_sdacha.html` | пять экранов сдачи и проверки: выполняет / отправлено / проверка учителем / оценена / на доработку |
| `classroom_zhurnal.html` | журнал с фильтрами и дневник ученика |
| `classroom_plitki.html` | библиотека плитками |
| `classroom_drag.html` | перетаскивание, переименование, меню плитки |
| `classroom_maket4.html` | оболочка редактора, последняя итерация |
| `classroom_maket.html` … `maket3.html` | предыдущие итерации, для истории |
| `uchenik_dz.html`, `classroom_uchenik.html` | раннее, перекрыто `uchenik_3varianta.html` |

Что из этого уже перенесено в `index.html` и что осталось — в `HANDOVER.md`.
