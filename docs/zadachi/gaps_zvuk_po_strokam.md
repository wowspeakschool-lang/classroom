# Задача платформе: звук у строки в блоке «Заполни пропуски»

Решение Анны от 23.10.2026 — делать. Кто делает: команда платформы
(`wowspeakschool-lang/wowspeak-platform`). Этот файл — постановка.

## Зачем

В младших курсах много заданий вида «Послушай слово и впиши пропущенные буквы».
Сейчас они собраны блоком «Короткий ответ» (`exact_input`): ребёнок видит слово
с пропуском (`ri__`) и печатает ответ в **отдельное поле справа**. Для 5–6-летнего
это два разных объекта: слово в одном месте, поле в другом, связь надо додумать.

Правильная картинка — окошки **внутри слова**, на месте пропусков:

```
было:   ri__        ▶     [ поле ввода на всю строку ]
надо:   r i [ ] [ ]  ▶
```

Так уже умеет блок «Заполни пропуски» (`gaps`, режим `type`): он рисует поля
ввода прямо в тексте. Единственное, чего ему не хватает, — **звука у строки**:
задание начинается со слова «Послушай», а у блока есть только один общий
плеер на весь блок (`payload.audio`), тогда как слов в задании пять-шесть и
у каждого свой звук.

## Что добавить

Два необязательных поля рядом с существующим `text`:

```json
{
  "mode": "type",
  "title": "Послушай слово и впиши пропущенные буквы",
  "text": "ri__n____g__\nd__u____c__k\ns__e____a__",
  "line_audio": ["https://…/ring.mp3", "", "https://…/sea.mp3"],
  "line_audio_tts": [{"text": "ring"}, {"text": "duck"}, {"text": "sea"}]
}
```

- `line_audio` — массив ссылок, по одной на строку `text` (строки делятся `\n`).
  Пустая строка в массиве или отсутствие элемента = у этой строки звука нет.
- `line_audio_tts` — разметка для «Озвучить пачкой», ровно как везде: кнопка
  находит пару «пустой `line_audio[i]` + `line_audio_tts[i]`», синтезирует и
  заполняет ссылку. Формат элемента — строка или `{text, voice}`.

Совместимость: старые блоки без этих полей работают как сейчас; общий
`payload.audio` остаётся и показывается над текстом, как и раньше.

## Как показывать

- В начале каждой строки, у которой есть `line_audio[i]`, — кнопка ▶ того же
  вида, что и остальные плееры курса.
- Кнопка не влияет на проверку и не считается ответом.
- В режимах `drag` и `choice` ведёт себя так же: звук у строки, поля прежние.

## Редактор

- У каждой строки текста — поле для ссылки на звук и кнопка «Озвучить», как у
  вариантов ответа в викторине.
- «🔊 Озвучить (N)» в редакторе и «Озвучить пачкой» в «Контент» → «Медиа»
  должны видеть `line_audio_tts` на общих основаниях.

## Что сделаем мы после этого

Переведём в «Заполни пропуски» 14 блоков, где сейчас стоит «Короткий ответ»:
SM0 — десять (юниты 2–5), SM1 — четыре (юниты 1, 3, 9). Звук там уже размечен,
переносится один в один. Новые задания такого вида будем собирать сразу
`gaps`-блоком.
