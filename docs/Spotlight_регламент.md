# Spotlight в тренажёре — регламент на класс

Порядок классов: 4 (сделан) → 5 → 6 → 7 → 8 → 9 → 10 → 11 → 3 → 2.
Один класс — один заход: план → промпты → заливка слов → картинки → коммит.

## 1. План колод (Claude)

Источник — `tools/spotlight/tsv/grade_N.tsv` (уже вычитан, дубли убраны).
Скрипт — копия `tools/spotlight/plan/g4_plan.py` → `gN_plan.py`, на выходе `plan/gN_plan.tsv`.

* **Папки:** Spotlight → Spotlight N → Module 1 … Module N → «Другие разделы».
* **Колоды:** юнит под его названием из учебника (`Unit 1: One big happy family!`).
  Большой юнит (больше ~15 слов) делится на темы: `Unit 3: The Animal Hospital · профессии`.
  Темы — по-русски, по смыслу: вещи, профессии, еда, спорт, животные, школьные принадлежности…
* **Culture Corner, Spotlight on Russia, Going Green, Spotlight on Exams и т. п.** — отдельные
  колоды в папке своего модуля, с названием раздела из учебника. Даже если там 1–2 слова.
* **Сказки, комиксы, Months, Numbers, страны, Useful English** — в «Другие разделы».
* Перевод — из учебника, ошибки учебника не повторяем. Часть речи в тренажёр не идёт.

## 2. Картинки: что есть, что рисовать (Claude)

* Ищем в тренажёре слово с картинкой (`lower(term)`), **сверяем перевод**: fair «светлый»
  ≠ «честный», wood «дерево» ≠ «лес». Совпало по смыслу — берём (копия `image_url` внутри базы).
* Не совпало или нет — рисуем.
* Без картинки: отвлечённые слова (hope, same, at least), фразы, связки.
* Числа — цифрами (`70`, `1st`), рисуем сами, не генератор.
* Страны и города — узнаваемое место + флаг на флагштоке, как в тренажёре.

## 4. Промпты (Claude)

* Листы по 6 картинок одной темы, сетка 3×2 (с 16.10.2026, ради 512×512; раньше 8–10).
* Каждый промпт **целиком в чате**, с полным блоком стиля, готовый к копированию.
  Файл — `docs/Тренажёр_SpotlightN_промпты.md`, источник — `tools/vocab-images/spN/sheets.py`.
* Мягко: без крови, ран и слёз. На предметах без надписей.
* В блоке стиля — «для детей»: без сигарет и алкоголя, одежда закрытая, у людей пять
  пальцев и обычная анатомия.
* Омонимы в одном классе — разные подписи: `lamb (meat)` и `lamb`.

## 5. Заливка слов (Claude, можно пока Анна генерирует)

`plan/gN_sql.py` → `sql/gN_1..4.sql`: папки → колоды → слова (по ~170 за запрос) → `word_count`.
Контроль: число колод, слов, слов с картинкой, `word_count` сходится.

## 6. Листы от Анны → нарезка (Claude)

* Нарезка `tools/vocab-images/spN/cut.py` (по образцу p7): очистка фона настроена на 300×300,
  в тренажёр идёт 512×512 (`out512/`, `hires.py`) — маска от 300, цвет из листа вдвое крупнее.
  Решение 16.10.2026: 512, «как лучше». В `cut()` нужен параметр `raw`, в `__main__` — `hires.make`.
* В тренажёре под картинкой белая подложка, поэтому режем **мягко** (`GENTLE = True`):
  только фон, связанный с краем листа. Глубокая вырезка белого съедала облака и футболки.
* **Проверка глазами до превью** — каждая картинка в натуральную величину
  (сетки 4×3: `python3 ../qc.py out g5 <листы>` из папки класса):
  * детям можно: без сигарет, алкоголя (бокалы, бутылки, бары), откровенной
    одежды и обнажённого тела — сюда же костюмы самбы, купальники взрослых,
    статуи без одежды, ночные клубы;
  * анатомия: число пальцев, рук, ног, глаз, лишние или сросшиеся конечности;
  * огрехи нарезки: кусок соседней картинки, остаток подписи.
  Плохое не уходит в тренажёр: пишем Анне, даём промпт на замену. Уже залитое —
  снимаем (`image_url = null`) до замены.
* Превью — по одному листу на картинку, на белой карточке, как в тренажёре.
* Анна отвечает: ок / перерисовать / оставить.

## 7. Загрузка картинок (Claude)

С 14.10.2026 тренажёр — в платформе (app.wowteach.ru), train.wowteach.ru закрыт,
туда ничего не класть. Порядок — `wowspeak-platform/CLAUDE.md`, «Картинки тренажёра»;
картинки выкладываются без отдельного «да» (решение владельца 15.10.2026).

1. `spN/export.py <листы>` → `wowspeak-platform/public/trainer/media/spotlightN/`, коммит в `main`.
2. Те же файлы — в ветку `gh-pages` репозитория wowspeak-team, `trainer/media/spotlightN/`,
   только эта папка, без `--force`.
3. Через минуту проверить адреса с сервера базы: `net.http_get(url)` →
   `net._http_response`, нужен `content-type = image/webp` (пока сервер не забрал
   ветку, отвечает 200 со страницей сайта).
4. Снимок `words_backup_YYYYMMDD_…` с RLS, затем `UPDATE … image_url` только там,
   где `image_url is null`. Перерезанную — под новым именем `…_v2.webp`.
5. Размер файлов — 512×512 (с 16.10.2026). Prepare 3–7 и вшитые в слова — 300×300, их листов у нас нет.
6. Чтобы 512 был честным, рисунок в листе должен быть крупным: для новых классов листы
   по 6 картинок (3×2), а не по 9–10 — тогда рисунок в листе около 450–500 точек.
