# Для разработчика: classroom ↔ кабинет ученика

Файл ведётся по ходу работы над classroom. Здесь только то, что нельзя сделать
внутри classroom и что нужно внести в кабинет ученика
(`app.wowspeak-online.ru/child`) или настроить у вас. Всё остальное classroom
делает сам.

Обновлено: 14.10.2026.

---

## Как это устроено

* **classroom** — `https://classroom.wowteach.ru`, статический сайт (GitHub Pages,
  репозиторий `wowspeakschool-lang/classroom`, всё приложение в `index.html`) +
  база Supabase (проект `vtcxghsqymwkyiogpndf`, прокси `https://api.wowteach.ru`).
* Учитель в classroom задаёт ученику урок (домашку) и срок сдачи.
* **Домашку ученик проходит на странице classroom**, а не в кабинете:

  ```
  https://classroom.wowteach.ru/?run=<lesson_id>&enroll=<enrollment_id>
  ```

  Страница сама показывает задания, сохраняет ответы, отправляет домашку
  учителю, после проверки показывает оценку, комментарии и переделку.
  Оформление подогнано под кабинет ученика.
* Кабинету нужно: **показать список заданных домашек и открыть эту страницу**.

## Что нужно от кабинета

### 1. Вход ученика в classroom — главное, без этого не работает

classroom узнаёт ученика по входу в Supabase (`auth.uid()`) и таблице-мосту:

```
classroom_student_links (auth_id uuid PK, student_id uuid UNIQUE → students.id, linked_at, linked_via)
```

Сейчас таблица пустая: у учеников нет входа. Общая сессия между поддоменами
работает через cookie на `.wowteach.ru`, а кабинет ученика живёт на **другом
домене** (`wowspeak-online.ru`), поэтому сама собой сессия не появится.

Нужно решить и сделать одно из:

* **А.** У ученика есть аккаунт Supabase (тот же проект). Кабинет при входе
  ребёнка создаёт/находит его и заполняет `classroom_student_links`; страницу
  classroom открывает с сессией (например, передав токен в адресе один раз,
  classroom его примет и сохранит).
* **Б.** Кабинет выдаёт короткоживущую подписанную ссылку на конкретную
  домашку; classroom по ней получает сессию ученика (нужна небольшая
  edge-функция Supabase — её можем написать с нашей стороны, если выберете Б).

Что выбрать — решаете вы, нам нужно знать, чтобы доделать приём входа на
стороне classroom.

### 2. Список домашек в кабинете

Функция в базе (вызывается от имени ученика после входа):

```
classroom_student_lessons(p_student_id uuid, p_course_id uuid) → jsonb
```

Возвращает `{ enrollment_id, lessons: [...] }`, у каждого урока:

| поле | что |
|---|---|
| `lesson_id`, `title`, `unit_title`, `kind` | урок (`homework` / `test`) |
| `assigned`, `active` | задан ли ученику и включён ли доступ |
| `deadline_at` | срок сдачи (ставит учитель) |
| `hw_status` | `null` — не начата · `in_progress` · `submitted` (ждёт проверки) · `reviewed` · `retake` (на переделку) |
| `score` | оценка, **только после проверки** |
| `submitted_at`, `reviewed_at` | даты |

Показывать в кабинете стоит только `active = true`. Кнопка «Открыть» ведёт на
страницу classroom (см. выше) — в той же вкладке или в новой, как удобнее.

Название домашки для ребёнка classroom собирает сам в виде шифра:
`SM2 Unit 1 Homework 1`, `GG1 Unit 3 Homework 2`, у Wow Dragon — `WD1 Homework 12`.
Если кабинету нужно то же название — скажите, добавим поле `code` в ответ.

### 3. Уведомления

Таблица `classroom_notifications` (`recipient_kind = 'student'`, `recipient_id =
students.id`): «Домашка проверена», «Нужно переделать». Если кабинет показывает
уведомления — можно читать отсюда. `payload.event` = `reviewed` / `retake`,
`payload.lesson_id`, `payload.enrollment_id`.

### 4. Возврат в кабинет

На странице classroom кнопка «← Домашка» ведёт назад. Нужен адрес, куда вести
(список домашек в кабинете). Сейчас — заглушка.

### 5. Монеты

В кабинете у ребёнка есть монеты. classroom их **не начисляет** (решение
методиста: пока без монет). Если позже понадобится — договоримся о событии
«домашка проверена, оценка N».

## Что уже сделано в classroom и вам делать не нужно

* сохранение ответов (в том числе без интернета), отправка, проверка учителем,
  комментарии учителя, переделка выбранных заданий, история попыток;
* оценка: проценты, у Wow Dragon — погода (солнышко / за тучкой / тучка /
  дождик) с кнопкой «для родителей: в процентах»;
* «серия»: огоньки за домашки подряд без опозданий;
* срок сдачи и плашки «Сделать сегодня» / «Просрочено»;
* заданная домашка заморожена: правки методиста ученику не видны.
