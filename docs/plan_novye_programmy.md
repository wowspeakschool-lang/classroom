# Новые программы простым вариантом — Go Getter 3–4, Prepare

Задача Анны от 13.11.2026: «Я потом хочу ещё добавлять домашки по другим
программам, там Go Getter 3–4, Prepare, но делать их в простом варианте, пока
по рабочей тетради. То есть просто брать их рабочую тетрадь и делать те
задания, которые там есть, но на нашей платформе».

Пока **не начинаем** — ждём её слова, с какой программы и какой тетради начать.
Файл нужен, чтобы задача не потерялась.

## Что это за режим

«Простой вариант» — не полный конвейер юнита (выгрузка «Взнания», планы уроков,
лесенка сложности, промпты на весь курс). Берём **рабочую тетрадь** и
переносим задания как есть, своим типом блока:

| в тетради | блок платформы |
|---|---|
| вписать слово в пропуск | `gaps` (`type`) или `exact_input` |
| выбрать вариант | `quiz` |
| соединить | `match` |
| расставить по порядку | `order` |
| распределить по группам | `sort` |
| подписать картинку | `hotspot` |
| написать о себе, рассказать | `task` · `speaking` |

Правила платформы при этом те же, что у остальных курсов (`CLAUDE.md`):
инструкция по-русски первой строкой, материал задания — в `material`,
серии сводим в один блок с `items`, образец не выдаёт ответ, звук размечаем
`*_tts` с точкой в конце, заливаем `is_published = false`.

## Чего не делаем

- Не придумываем задания сверх тетради и не «добираем до 6–8» — это правило
  для курсов, собранных по планам уроков.
- Не переносим то, что на бумаге работает, а на экране нет: раскраски,
  «обведи», «соедини карандашом по пунктиру», «вырежи и наклей».
- Не заводим курс в базе, пока Анна не назовёт программу: `slug`, название и
  `sort_order` — её решение (Go Getter 3 уже есть, там только тесты;
  Go Getter 4 и Prepare в базе нет).

## Картинки: тетради чёрно-белые

Главная сложность. Если картинка нужна для ответа (подписать предмет, выбрать
по картинке, найти отличие), чёрно-белый скан не годится — нужна **точно такая
же картинка, только цветная**, один в один по составу: те же предметы, та же
поза, то же количество, то же расположение.

Порядок (решение Анны 13.11.2026 — «через промпт, через меня»):

1. вырезаем картинку из тетради и смотрим на неё: что именно от неё зависит
   в ключе задания;
2. пишем промпт, который описывает её состав дословно (сколько предметов, что
   где стоит, какие цвета задаёт ключ), со строкой стиля курса;
3. **промпт идёт Анне в чат** — одним цельным блоком кода, готовым к
   копированию, все промпты одним сообщением;
4. она генерирует, присылает листы;
5. режем, жмём в webp, показываем превью, ждём «ок», ставим в блоки.

Если картинка не влияет на ответ (украшение, фон), её можно просто не
переносить — задание от этого не ломается.
