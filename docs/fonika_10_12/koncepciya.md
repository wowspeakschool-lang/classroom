# Курс фоники 10–12 — концепция: история, мотивация, устройство урока (черновик 16.11.2026)

План утверждён Анной 11–16.11.2026 (`plan_kursa.md`): модуль 1 — буквы (1–5),
алфавит (6), «волшебная e» (7), sh ch th (8), ee oo ar (9), тест (10);
модуль 2 не делаем (решение Анны 19.11.2026: курс — один модуль, 10 уроков).

## Формат

Интерактивный урок HTML на платформе, как Halloween (`lessons/halloween/`):
экраны по порядку, «Next», кнопка «⭐ Extra» — это «If time». Переключатель
30 / 40 минут: в режиме 40 появляются дополнительные экраны. К уроку — план
для учителя в формате SM0 (`kind='lesson'`, первым блоком `embed`), домашка
6–8 заданий на платформе.

## История — «Код» (агенты-дешифровщики), утверждена Анной 19.11.2026

Механика шифра (символ ↔ буква, ключ внизу, сочетания — склейка открытых
символов) — в `struktura_uroka.md`.

Чтение по-английски и есть расшифровка (decoding), поэтому метафора честная:
ученик не «учит буквы, как малыш», а взламывает код.

- **Герои** — девочка и мальчик 11–12 лет (решение Анны 19.11.2026):
  **Sam** (Саманта) и **Dan**, имена читаются уже к уроку 2 (s a m · d a n). Плюс куратор — «Агент Икс», появляется только
  голосом и сообщениями.
- **Завязка:** в городе кто-то оставляет зашифрованные записки, тег на стене,
  сообщения в чате школы. Прочитать их могут только те, кто знает код.
- **Каждый урок — миссия.** Новые звуки — новые ключи шифра; в конце урока
  приходит сообщение, которое теперь можно прочитать (декодируемый текст из
  пройденного). Алфавит (урок 6) — «мастер-ключ», «волшебная e» (урок 7) —
  «хитрость с немой буквой», sh ch th (урок 8) — «двойные коды».
- **Урок 10** — финальное дело: длинное сообщение, ученик раскрывает, кто
  оставлял записки.
- **Модуль 2** — второй сезон, новое дело.

Тексты — переписка в мессенджере, записки, объявления, короткие сцены:
то, что подросток читает в жизни.

**Другие варианты:** «Блогеры» (двое ведут канал, ученик читает подписи и
комментарии) — современно, но слабее держит сюжет; «Эскейп-рум» (каждый урок —
комната, замок открывается словом) — хорошо для игр, но без героев.

## Мотивация — для 10–12 лет

Главный мотиватор у отстающего подростка — **видимый рост собственного
умения**, а не наклейки.

1. **Счётчик слов** — в конце урока: «Теперь ты можешь прочитать 140 слов»
   (считаем по пройденным звукам). Растёт с каждым уроком.
2. **Личный рекорд скорости** — чтение списка слов на время; соревнование
   только с собой.
3. **Кодовая колода** — карточки выученных звуков, пополняются каждый урок,
   с них начинается каждый урок (то же, что полоса Read & Review в Genki).
4. **Ранг агента** — новичок → агент → старший агент → дешифровщик
   (уроки 1, 4, 7, 10), сертификат в конце модуля (canvas, как в Halloween).
5. **Class Dojo не используем** (решение Анны 19.11.2026: «у нас своя система
   геймификации — монетки на платформе»). Из других планов тоже уберём потом.
6. Тон — уважительный: учитель по-русски объясняет, зачем это (школьный
   английский станет легче), без «молодец, зайка».

## Урок: 30 минут + 10 минут + If time

| экран | 30 мин | +40 мин |
|---|---|---|
| 1. Брифинг миссии: пришло сообщение, прочитать пока нельзя | 1 | |
| 2. Кодовая колода: все пройденные звуки, быстро | 3 | + слова на скорость, личный рекорд |
| 3. Новые звуки: звук, как произносится, буква, 4 слова с картинками | 5 | |
| 4. Сливаем: нажми на буквы → звуки → слово; собери слово из плиток | 7 | + сортировка слов по звуку |
| 5. Пароли: 1–2 слова-исключения | 2 | |
| 6. Диктант: слово на слух → собрать / написать | 4 | + второй диктант |
| 7. Расшифруй сообщение: история + 2–3 вопроса «верно / неверно» | 6 | + перечитать на время / по ролям |
| 8. Миссия выполнена: счётчик слов, ранг, ДЗ | 2 | |
| ⭐ If time — 2–3 игры | | |

Игры для If time: «Скоростной дешифратор» (слова мелькают, успей прочитать),
«Настоящее слово или фейк?» (sat / pim — проверка, что ученик именно
читает, а не угадывает), «Взломщик» (слово с пропущенной буквой),
«Найди слово» в сетке букв.

Для русскоязычных отдельно на экране 3: h ≠ х, w, th; краткие a / e;
похожие на русские буквы (p c x y H B).

## Что нужно решить до сборки

- звуки (фонемы) — синтез отдельные звуки (/s/, /æ/) озвучивает плохо;
  нужны записи голосом (как буквы Wow Dragon) — около 30 файлов на модуль 1;
- героев рисуем сами (это наши герои, не учебника), стиль Go Getter
  (полуреалистичный 3D); генератор плохо держит одно лицо от картинки к
  картинке — героев делаем 4–6 фиксированными кадрами (позы, эмоции) и
  переиспользуем, а сцены рисуем без лиц крупно.

## Решения Анны 19.11.2026 (второе сообщение)

- **Звуки букв и сочетаний — с сайта Show and Tell Letter**:
  https://www.showandtellletter.com/alphabet-sounds/#practice-deck. Анна сама
  скачивает алфавит и сочетания; потом ставим их и в фонику, и **в домашки
  других курсов, где сейчас её записи отдельных звуков** (Wow Dragon, SM0).
- **Игры — не «выбери вариант».** В каждом уроке хотя бы пара интересных игр
  под возраст: сортировка слов по услышанному звуку, «поймай звук», «магниты
  на холодильнике» (собери слово из букв) и т. п. Придумываем при составлении
  плана каждого урока.
- **Скелет урока нравится** («потом будет понятнее, когда сделаем»).
- **Порядок работы:** программа по урокам красиво — PDF или презентация →
  урок 3 целиком (урок + домашка, не публикуем) → Анна отправляет методисту,
  которая просила такой курс → остальные уроки.
