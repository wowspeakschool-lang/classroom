# «Впиши пропуск» в тесте: одна клеточка вместо слова и список без верного ответа

Нашла Анна 10.11.2026 на GG2 Unit 6 Test, задание 4: «ученик не может вписать
слово целиком, он может ввести только одну букву». Это не одно задание —
ломаются **все блоки `gaps` в тестах**, по одной и той же причине.

## Причина

Ученику тест отдаётся замаскированным: `classroom_run_blocks` зовёт
`classroom__mask_block`, и для `gaps` та вырезает ответ прямо из текста:

```sql
p := jsonb_set(p, '{text}',
      to_jsonb(regexp_replace(coalesce(p->>'text',''), '__([^_]+)__', '__…__', 'g')));
```

То есть у ученика в `text` стоит `__…__`, и `gapsParse` возвращает
`accept = ['…']`. А рендер `GapsBlock`
(`src/public/homework/blocks.tsx`) берёт размер и варианты **из этого же
ключа**:

```ts
const len = Math.max(1, ...x.accept.map((w) => w.length))   // ширина поля
const key0 = x.accept[0] ?? ''
if (!/\s/.test(key0) && key0.length > 0 && Array.from(key0).length <= 14) {
  return <GapCells n={Array.from(key0).length} … />          // клеточка на букву
}
```

`'…'` — один символ, поэтому `GapCells` рисует **одну клеточку**: больше одной
буквы вписать некуда. До клеточек (ТЗ `docs/tz_platforma_gaps_kletki.md`,
06.11.2026) было не лучше: ширина считалась тем же `len`, то есть поле было
шириной в один символ.

В режиме `choice` та же причина даёт другой симптом: список вариантов
собирается как «верный из `accept[0]` плюс неверные из `choices[idx]`», а
`accept[0]` у ученика — `'…'`. В выпадающем списке стоят `…` и неверные
варианты, **верного нет вовсе** — задание нельзя выполнить правильно.

В домашках этого нет: маскируются только уроки с `kind='test'`.
Режим `drag` не задет: банк фишек `classroom__mask_block` собирает из текста
**до** замены, поэтому фишки настоящие.

## Сколько задач задето (10.11.2026)

| режим | блоков в тестах | что видит ученик |
|---|---|---|
| `type` | 23 | одна клеточка на одну букву |
| `choice` | 4 | в списке нет верного варианта |
| `drag` | 24 | работает |

`type`: GG2 — 8 (юниты 0, 1, 3, 4, 5, 6, 7, 8), SM1 — 8 (юниты 0, 1, 2, 3, 4,
7, 8, 9), SM0 — 4, GG1 — 1, SM2 — 1, SM3 — 1.
`choice`: GG3 Unit 0 Test (блоки 4, 8, 11), SM2 Unit 2 Test (блок 5).

## Что сделать

Рендер не должен определять ни ширину, ни варианты по ключу, которого у
ученика нет. Договоримся о явной метке: маска ставит `__…__`, рендер её
узнаёт.

1. **`type`.** Если ключ пропуска — метка (`'…'`), не рисовать клеточки и не
   считать ширину по ключу: обычное поле ввода разумной ширины (≈12 ch).

```ts
const MASK = '…'
const key0 = x.accept[0] ?? ''
const masked = key0 === MASK
const len = masked ? 12 : Math.max(1, ...x.accept.map((w) => w.length))
if (!masked && !/\s/.test(key0) && key0.length > 0 && Array.from(key0).length <= 14) {
  return <GapCells n={Array.from(key0).length} … />
}
```

2. **`choice`.** Верный вариант должен попадать к ученику, но не быть
   помеченным. Со стороны базы маска для `mode = 'choice'` кладёт в
   `choices[idx]` полный список (верный + неверные) в перемешанном порядке —
   эту правку делаем мы миграцией, она на стороне `classroom__mask_block`.
   Со стороны рендера: если ключ — метка, список брать **целиком** из
   `p.choices[idx]`, не подставляя `accept[0]`:

```ts
const choicesOf = (idx: number, accept: string[]): string[] => {
  const raw: unknown = Array.isArray(p.choices) ? p.choices[idx] : null
  const list = (Array.isArray(raw) ? raw : []).map((c) => String(c ?? '').trim()).filter(Boolean)
  if ((accept[0] ?? '') === MASK) return list          // в тесте список уже полный и перемешан
  const wrong = list.filter((c) => !accept.includes(c))
  const all = [accept[0] ?? '', ...wrong].filter((c, j, arr) => c && arr.indexOf(c) === j)
  return shuffle(all, `${id}:g${idx}`)
}
```

Порядок выкладки: сначала правка рендера, потом миграция базы — тогда
промежуточного состояния, в котором ученик видит верный вариант помеченным,
не возникает.

## Проверка

Открыть любой тест из таблицы «глазами ученика» (не в режиме проверки, где
ответы показываются): в `type` поле должно принимать слово целиком, в `choice`
верный вариант должен быть в списке, и `…` в списке быть не должно.
В домашке с диктантом («впиши буквы») клеточки должны остаться как были.
