# ТЗ: преподаватель удаляет задание, заданное по ошибке

Решение Анны от 05.11.2026. Преподаватель случайно задал ученику не ту домашку и хочет её убрать.

**Главное правило:** удалённое задание исчезает совсем — у ученика, у преподавателя, в журнале, в отчётах. Отметки «снято», зачёркнутой строки, истории «было задано» нет нигде в интерфейсе. Для ученика это выглядит так, будто задания не было.

## Что есть сейчас

| что | как сейчас | чего не хватает |
|---|---|---|
| Домашка и тест платформы | «Задать материал» → ученик → «Все материалы» → галочка «Доступ» ставит урок **на паузу** (`classroom_set_lesson_active`, `status = 'paused'`) | пауза остаётся видна; во вкладке «Задано» снять нельзя; в окне урока (расписание) — тоже нельзя |
| Задание тренажёра | список заданий → кнопка «Снять» (`trainer_assignment_set`, `status = 'paused'`), строка остаётся с «⏸ снят» | удаления нет |

База уже разрешает это преподавателю: правило `classroom_assignments_write` пускает его к **своим** назначениям (`assigned_teacher_id` = он), методиста и руководство — ко всем. Нужна функция удаления и кнопки.

## 1. Кнопка «Удалить» — где

1. **«Задать материал» → ученик → «Задано»**: у каждой строки (домашка, тест) — «🗑 Удалить».
2. **Окно урока в расписании**, блок домашки с платформы (`PlatformHomework`): у уже заданной домашки — «Удалить».
3. **Журнал ДЗ**: у строки — «Удалить» (в «⋯» строки, чтобы не нажать случайно).
4. **Тренажёр, список заданий ученика**: рядом с «Снять» — «🗑 Удалить».

Кто видит кнопку: преподаватель — только у заданий, которые задал он сам; методист и руководство — у всех.

## 2. Подтверждение

Перед удалением — окно:

> Удалить «Homework 3» у ученика Иван Петров?
> Задание пропадёт у ученика и из журнала. Вернуть его можно только заново, кнопкой «Задать».
> [Удалить] [Отмена]

Если ученик **уже начал** (есть хотя бы один ответ) или **уже отправил** — в окне строка красным:

> ⚠️ Ученик уже начал (ответил на 4 задания из 12). Его ответы тоже удалятся.

Если работа **уже проверена** учителем — то же предупреждение плюс «Оценка тоже удалится».

## 3. Что удаляется (функция базы)

Одна функция, например `classroom_unassign(p_student_id uuid, p_lesson_id uuid)`, `security definer`, с той же проверкой прав, что у правила записи (свой учитель или редактор). Удаляет **у этого ученика по этому уроку**:

- строку назначения `classroom_assignments` (`target_type = 'student'`, `target_id` = ученик, `lesson_id`);
- его прогресс по уроку `classroom_progress` (запись ученика в этом курсе + урок);
- его ответы `classroom_submissions` по блокам этого урока;
- его замороженную копию урока `classroom_lesson_snapshots`;
- комментарии учителя к этой работе `classroom_comments` и оценку `classroom_grades`, если есть;
- ссылку на тест `classroom_test_links`, если это тест;
- непрочитанные уведомления ученику и родителю про это задание (`classroom_notifications`, где в `payload` этот урок) — чтобы не пришло «вам задали» про удалённое.

Для тренажёра — `trainer_assign_delete(p_id uuid)`: удаляет строку `trainer_assignments` (результаты лежат в ней же) с той же проверкой, что `trainer_assignment_set`.

**Тихий журнал для разбора споров** (не показывается в интерфейсе): перед удалением одна строка в отдельную таблицу `assignment_deletions` — кто, когда, какому ученику, какой урок, был ли начат, сколько было ответов. Таблица с RLS, читает только руководство. Нужна, если родитель скажет «ребёнок делал, а всё пропало».

После удаления ученик в кабинете задания не видит, преподаватель — ни во «Задано», ни в журнале, ни в «На проверку», ни в нагрузке. Если преподаватель задаст тот же урок заново — он придёт чистым, как новый.

## 4. Что ещё стоит добавить рядом (на выбор Анны)

1. **«Заменить на другую»** в том же окне подтверждения: удалить и сразу открыть выбор нужной домашки этому ученику — частый случай «задал не ту».
2. **Удалить у всей группы сразу**: если задавал группе (`AssignSection`, режим по группе) и ошибся — одна кнопка вместо удаления у каждого ученика.
3. **Поменять срок прямо во «Задано»** — сейчас срок меняется только во «Все материалы».
4. **Вернуть отправленную работу ученику в работу** («ученик нажал „Отправить“ случайно») — без удаления ответов, статус снова «в работе».
5. **Отменить по ошибке поставленную оценку / «Принято»** — вернуть работу в «На проверку».
6. **Удалить по ошибке оставленный комментарий учителя** (`classroom_comment_remove` в базе уже есть — проверить, есть ли кнопка у учителя).

## 5. Проверка перед выкладкой

- Преподаватель не видит «Удалить» у чужого задания; вызов функции с чужим заданием отбивается базой.
- Удалили неначатое → у ученика пропало из кабинета, у учителя — из «Задано» и журнала.
- Удалили начатое → предупреждение было; ответы, прогресс, копия урока удалены; в «На проверку» строки нет.
- Задали тот же урок снова → ученик видит его чистым, без старых ответов.
- Тренажёр: удалили → пропало у ученика и из списка, «⏸ снят» не осталось.
- В `assignment_deletions` на каждое удаление по строке.
