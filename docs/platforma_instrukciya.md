# Уроки и домашки на платформе — инструкция

17.10.2026. Всё, что было на classroom.wowteach.ru, теперь на платформе
app.wowteach.ru. Вход тот же. Старый раздел «Уроки» (classroom внутри окна) из
меню убран. Ученикам ничего делать не нужно: ссылки на домашку в кабинете
работают как раньше.

## Где что

| Что | Кому | Где в меню |
|---|---|---|
| Провести урок по плану на весь экран | преподаватель, методист | «Материалы» (у методиста — «Контент») → «Планы уроков» |
| Найти материал, посмотреть глазами ученика | преподаватель, методист | «Материалы» (у методиста — «Контент») → «Библиотека» |
| Задать ДЗ (срок ставится сам — к следующему уроку) | преподаватель | «Материалы» → «Задать ДЗ» |
| Проверить сданную работу, уведомления | преподаватель | «Материалы» → «Проверка ДЗ» |
| Править урок (редактор) | методист | «Контент» → «Библиотека» → курс → юнит → «Редактировать» у материала |
| Загрузить картинку или звук, озвучить пачкой | методист | «Контент» → «Медиа» |
| Сообщения учителей ⚑, сложные задания, нагрузка | методист | «Контент» → «Контроль качества» |
| Кто что сделал по домашкам, выгрузка | методист | «Контент» → «Журнал ДЗ» (по клетке — сроки и «👁 Урок») |

## Преподавателю

Всё для уроков и домашек — в левом меню, в списке «▾ Материалы» (с 19.10.2026).
Щелчок по «Материалы» сворачивает и разворачивает список. Если у вас есть ещё
роль (методист, ассессор), список — в разделе «Преподаватель».

### Провести урок

1. «Планы уроков» → курс → юнит → урок.
2. «▶ Показ» — план откроется в новой вкладке. Её и выводите ученику в Zoom
   (демонстрируйте вкладку, а не весь экран).
3. Листать — стрелками ← → или пробелом. Esc — закрыть, ⛶ — на весь экран,
   A− / A+ — размер.
4. Сверху — только те переключатели, что в этом плане что-то меняют
   (с 19.10.2026): «индивидуально / в группе» — если в плане есть врезки
   для группы, «30 / 40 минут» — если есть блоки под длительность, «по одному
   / все блоки» — если план из нескольких блоков. «Показать ответы» — верные
   ответы под заданием (перед учеником не включайте). Если в плане встроен
   интерактивный урок (например, Halloween в курсе Holidays), он открывается
   на весь экран, план — кнопкой 📋 внутри урока.
5. Задания на экране можно выполнять вместе с учеником — ответы никуда не
   сохраняются.

«Глазами ученика» у планов уроков убран (19.10.2026): план ученику не показывают.

### Посмотреть домашку до выдачи

«Библиотека» → материал → «👁». Откроется так, как увидит ученик, и под каждым
заданием — верный ответ. Галочка «Скрыть ответы» — если показываете экран.

### Задать ДЗ

«Задать ДЗ» → ученик → отметить материалы → «Задать». Срок ставится сам — до
начала следующего урока ученика. Поменять срок одному ученику — в его карточке.
В карточке ученика видно, что задано, что сдано и что ждёт проверки.

### Проверить

«Проверка ДЗ» — сданные работы. «Проверить →» — работа
ученика: можно поправить вердикт по пункту, поставить балл за устные и
письменные, оставить комментарий. Всё сохраняется сразу. Дальше — «Завершить
проверку» или «На доработку» (целиком или отмеченные задания, с новым сроком).

Вверху «Проверки ДЗ» — блок «🔔 Новое»:

- 🎤 «ответил(а) текстом» — ученик сдал устные задания текстом, без
  микрофона. С третьего раза за месяц — просьба связаться с родителями
  через ассистентов.
- ✅ / 💬 — методист ответил на ваше сообщение об ошибке ⚑.

«✓» — отметить прочитанным. Красное число у «Проверки ДЗ» в меню — работы на
проверке плюс новое.

Нашли ошибку в задании (неверный ответ, битый звук) — в работе ученика
нажмите ⚑ у задания и опишите. Методист увидит это в «Контроле качества».

## Методисту

### Править урок

«Библиотека» → курс → юнит → материал → «Редактировать».

- Блоки свёрнуты в строки. ▸ — развернуть, номер слева — вписать другой, и
  блок встанет на это место. ↑ ↓ — сдвинуть, ⧉ — копия, ⇄ — пересобрать в
  другой тип на тех же словах (карточки → квиз, пары, «впиши»), 🗑 — удалить,
  ＋ — вставить новый блок после этого.
- Внизу — выбрать тип и «+ Блок».
- Звук у любого поля: 🎵 файл, 🎤 записать голосом, 🔊 озвучить синтезом,
  🔇 убрать. Можно вставить ссылку.
- Пропуски: выделите слово в тексте и нажмите «Сделать пропуск из
  выделенного».
- Точки на картинке: загрузите картинку и щёлкайте по ней.
- Материал можно «Собрать слайдом»: выбрать макет (карточки, сетка слов,
  картинка и текст…), цвет, «if time». Предпросмотр — под формой.
- У плана урока у каждого блока: кому виден (обоим / преподавателю /
  ученику), режим, длительность; для текста — врезка «В группе».
- ↶ ↷ — отменить и вернуть (или Ctrl+Z / Ctrl+Shift+Z вне полей ввода).
  ☰ Оглавление — быстро перейти к блоку.
- Вверху: готовность (что ждёт озвучки, где нет картинки), соседние
  материалы юнита, «Опубликован», порог зачёта, «переименовать».
- Сохранение — «💾 Сохранить урок» внизу. Пока не сохранили, внизу горит
  «не сохранено».

Полезно знать:

- Несохранённые правки остаются на этом устройстве. Закрыли вкладку — при
  следующем открытии урок предложит «Вернуть правки».
- Если урок успели сохранить в другом окне, пока он был открыт у вас,
  платформа спросит, сохранять ли поверх.
- Урок у ученика замораживается при первом ответе: начавший ученик правку
  не увидит.
- «👁 Глазами ученика» в редакторе домашки показывает сохранённую версию (у плана урока этой кнопки нет).

### Озвучка

- «🔊 Озвучить (N)» в редакторе — озвучить всё, что помечено к озвучке в этом
  уроке. Звук ложится в редактор, потом сохраните урок.
- «Медиа» → «🔊 Озвучить пачкой» — по нескольким урокам сразу. Пишет прямо в
  базу; открытый в редакторе урок после этого откройте заново.
- Пока сервер озвучки не настроен для платформы, синтез выдаёт ошибку «Сервер
  озвучки не ответил платформе». Тогда запишите голосом, загрузите файл или
  озвучьте в classroom.wowteach.ru — он пока работает.

### Медиа

«Медиа» → выбрать файлы → «Загрузить» → «Копировать» у ссылки. Ниже —
недавние загрузки, ссылку можно взять и потом.

### Контроль качества

- «Сообщения учителей» — ⚑ из проверки. Ответьте и закройте: «Исправлено»
  или «Не ошибка» (учитель увидит ответ в «Новом»). «Открыть» — урок в
  редакторе.
- «Сложные задания» — где ученики чаще всего ошибаются и что отвечают
  неверно: часто это ошибка в ответе задания.
- «Учителя» — у кого сколько работ ждёт проверки и сколько дней.

### Новый юнит

Как раньше: конвейер в репозитории classroom (`tools/`), картинки — в `media/`,
уроки — в базу черновиками. Потом «Библиотека» → проверить через 👁 →
опубликовать («⋯» → «Опубликовать» или «☰ Списком» → галочки → «✓
Опубликовать»).

## Тому, кто ведёт сервер озвучки

Зачем: кнопка 🔊 «озвучить» в редакторе платформы обращается к серверу
api.wowteach.ru (`/tts`). Сервер сейчас разрешает это только старому сайту
classroom.wowteach.ru, а платформе (app.wowteach.ru) — нет. Нужно разрешить
обоим. Правка — одна настройка nginx, минут 5, остальное не затрагивает.

1. Найти блок `location /tts` в настройках nginx:

   ```
   grep -rn "location /tts" /etc/nginx/
   ```

2. Сделать копию файла, который нашёлся (на случай отката):

   ```
   cp <файл> <файл>.bak-tts
   ```

3. В блоке `location /tts` строку

   ```
   add_header Access-Control-Allow-Origin  "https://classroom.wowteach.ru" always;
   ```

   заменить на

   ```
   set $cors "";
   if ($http_origin ~ ^https://(classroom|app)\.wowteach\.ru$) { set $cors $http_origin; }
   add_header Access-Control-Allow-Origin $cors always;
   add_header Vary Origin always;
   ```

   Если строка с `classroom.wowteach.ru` в блоке не одна (например, ещё
   внутри `if ($request_method = OPTIONS)`), в остальных местах заменить её
   на `add_header Access-Control-Allow-Origin $cors always;`. Остальные строки
   блока не трогать.

4. Проверить настройку и перезагрузить nginx:

   ```
   nginx -t && systemctl reload nginx
   ```

   Если `nginx -t` пишет ошибку — вернуть копию из шага 2 и написать нам.

5. Проверка: команда

   ```
   curl -s -o /dev/null -D - -H "Origin: https://app.wowteach.ru" https://api.wowteach.ru/tts | grep -i access-control-allow-origin
   ```

   должна показать `https://app.wowteach.ru`. Сейчас (19.10.2026) показывает
   `https://classroom.wowteach.ru` — это и значит, что платформу не пускают.
   Старый сайт после правки работает как раньше.
