# Озвучка 4–6 через Yandex SpeechKit — пошагово

Всё делается один раз и занимает полчаса. Дальше запись любой реплики —
одна строчка в командной строке.

Весь комплект — **120 дорожек, 4623 знака**. По тарифу SpeechKit это
0.4 ₽ за 1000 знаков, то есть **около двух рублей** за полный прогон.
При регистрации Яндекс даёт пробный грант, так что первые прогоны уйдут
в него.

---

## Часть 1. Ключ Яндекса

Нужны две строки: **API-ключ** и **идентификатор каталога**. Ниже — где их взять.

**1.1.** Откройте [console.yandex.cloud](https://console.yandex.cloud) и войдите
обычным Яндекс-аккаунтом (почта на @yandex.ru подойдёт).

**1.2.** При первом входе консоль предложит создать облако и каталог —
соглашайтесь со всем по умолчанию. Каталог обычно называется `default`.

**1.3.** Привяжите платёжный аккаунт: слева **Биллинг** → создать
платёжный аккаунт, карта, подтверждение. Без него синтез не работает даже
на грант. Списывать будет копейки, но карта нужна.

**1.4. Идентификатор каталога.** Слева вверху выберите каталог `default`.
На его странице, в блоке «Обзор», есть строка **Идентификатор** —
что-то вроде `b1gxxxxxxxxxxxxxxxxx`. Скопируйте, это наш `FOLDER`.

**1.5. Сервисный аккаунт.** В каталоге слева → **Сервисные аккаунты** →
**Создать сервисный аккаунт**. Имя любое, например `tts`. Там же
**Добавить роль** → в поиске наберите `speechkit` → выберите
**`ai.speechkit-tts.user`**. Создать.

**1.6. API-ключ.** Откройте созданный аккаунт → вкладка **Ключи доступа**
(или кнопка **Создать новый ключ** справа вверху) → **Создать API-ключ**.
Если спросит область действия — оставьте предложенную по умолчанию.

Ключ вида `AQVNxxxxxxxxxxxxxxxxxxxx` **покажут один раз**. Скопируйте его
сразу; закроете окно — придётся создавать новый (это не страшно).

> Названия кнопок в консоли иногда меняются. Ориентируйтесь на слова
> «Сервисные аккаунты», «Роль», «API-ключ» — сами разделы на месте.

## Часть 2. Python на компьютере

**2.1.** [python.org/downloads](https://www.python.org/downloads/) → большая
кнопка **Download Python** → запустите скачанный файл.

**2.2.** В первом окне установщика — **обязательно** поставьте галочку
внизу **«Add python.exe to PATH»**, и только потом **Install Now**.
Без галочки командная строка Python не найдёт.

**2.3.** Проверка: клавиши **Win+R** → наберите `cmd` → Enter. В чёрном
окне наберите:

```
python --version
```

Должно ответить `Python 3.13.x` (номер любой). Если пишет «не является
внутренней или внешней командой» — установщик прошёл без галочки из 2.2,
переустановите.

Ничего больше ставить не нужно: скрипту хватает того, что идёт с Python.

## Часть 3. Запуск

**3.1.** Создайте папку, например `C:\wowspeak`, и положите туда файл
**`ozvuchka.py`**, который я пришлю.

**3.2.** Откройте `ozvuchka.py` Блокнотом (правой кнопкой → Открыть с
помощью → Блокнот). В самом начале файла две строки:

```python
KEY = ""        # API-ключ сервисного аккаунта, начинается на AQVN
FOLDER = ""     # идентификатор каталога, начинается на b1g
```

Впишите своё **внутрь кавычек**:

```python
KEY = "AQVNxxxxxxxxxxxxxxxxxxxx"
FOLDER = "b1gxxxxxxxxxxxxxxxxx"
```

Сохраните (Ctrl+S). Кавычки оставить, они обязательны.

**3.3. Сначала образцы голосов.** В командной строке:

```
cd C:\wowspeak
python ozvuchka.py obrazcy
```

Рядом появится папка `obrazcy` — в ней по одному mp3 на каждый голос,
все говорят одну и ту же фразу Искорки. Послушайте.

Часть имён скрипт пропустит с пометкой «нет такого голоса» — это нормально,
список нарочно шире: какие голоса у сервиса есть на самом деле, видно
только по ответу.

**3.4. Если голос хочется другой** — в том же файле чуть ниже таблица:

```python
VOICES = {
    "firefly": ["alena", "good"],     # светлячок Искорка
    "bunny": ["jane", "good"],        # зайчик
    "hedgehog": ["ermil", "good"],    # ёжик
    "fox": ["zahar", "good"],         # лисёнок
    "en": ["john", None],             # английские слова
    ...
}
```

Замените имя голоса на понравившееся из папки `obrazcy`. Второе слово —
роль (интонация): `"good"` — доброжелательно, `"neutral"` — ровно,
`None` — без роли. Если голос роль не поддерживает, скрипт сам повторит
запрос без неё, ломаться ничего не будет.

**3.5. Запись всего.** Там же:

```
python ozvuchka.py
```

Пойдут строчки `RU-01`, `RU-02`… Все файлы лягут в папку `audio-4-6`
рядом со скриптом. Минуты три-четыре.

Уже записанное скрипт не трогает: запустите ещё раз — допишет только
недостающее. Переписать одну реплику заново:

```
python ozvuchka.py RU-05
```

(сначала удалите `audio-4-6\RU-05.mp3` — или просто назовите номер, скрипт
перезапишет именно его).

**3.6.** Загрузите папку `audio-4-6` в Google Drive и напишите мне. Я
вставлю дорожки в урок и пройду его заново с настоящими длительностями:
кнопки и паузы сейчас рассчитаны на тишину, под запись их надо подстроить.

## Если что-то пошло не так

| Что видно | Что это |
|---|---|
| `python не является внутренней...` | нет галочки «Add python.exe to PATH», переустановить Python |
| `Не вписаны KEY и FOLDER` | пустые кавычки в начале файла |
| `401` или `403` | ключ скопирован не целиком, либо сервисному аккаунту не выдана роль `ai.speechkit-tts.user`, либо каталог не тот |
| `Дорожка RU-07 не записалась: 400 ...` | пришлите мне текст ошибки целиком, это по моей части |
| Окно закрылось само | запускайте из командной строки (`cmd`), а не двойным щелчком |
