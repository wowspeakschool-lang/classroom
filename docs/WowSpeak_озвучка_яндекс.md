# Озвучка 4–6 через Yandex SpeechKit — пошагово

От вас — ключ Яндекса и две настройки окружения, минут двадцать один
раз. Дальше записываю я, и переписать потом любую реплику — одна строчка.

Записываем **только русские реплики** — 73 дорожки, 4185 знаков.
Английские слова читает синтез браузера, и читает хорошо; их не трогаем.

По тарифу SpeechKit это 0.4 ₽ за 1000 знаков, то есть **меньше двух
рублей** за полный прогон.
При регистрации Яндекс даёт пробный грант, так что первые прогоны уйдут
в него.

---

## Часть 1. Ключ Яндекса

Нужны две строки: **API-ключ** и **идентификатор каталога**. Ниже — где их взять.

**1.1.** Откройте [console.yandex.cloud](https://console.yandex.cloud) и войдите
обычным Яндекс-аккаунтом (почта на @yandex.ru подойдёт).

**1.2.** При первом входе консоль предложит создать облако и каталог —
соглашайтесь со всем по умолчанию. Каталог обычно называется `default`.

**1.3.** Привяжите платёжный аккаунт: слева **Биллинг** → создать
платёжный аккаунт, карта, подтверждение. Без него синтез не работает даже
на грант. Списывать будет копейки, но карта нужна.

**1.4. Идентификатор каталога.** Слева вверху выберите каталог `default`.
На его странице, в блоке «Обзор», есть строка **Идентификатор** —
что-то вроде `b1gxxxxxxxxxxxxxxxxx`. Скопируйте, это наш `FOLDER`.

**1.5. Сервисный аккаунт.** В каталоге слева → **Сервисные аккаунты** →
**Создать сервисный аккаунт**. Имя любое, например `tts`. Там же
**Добавить роль** → в поиске наберите `speechkit` → выберите
**`ai.speechkit-tts.user`**. Создать.

**1.6. API-ключ.** Откройте созданный аккаунт → вкладка **Ключи доступа**
(или кнопка **Создать новый ключ** справа вверху) → **Создать API-ключ**.
Если спросит область действия — оставьте предложенную по умолчанию.

Ключ вида `AQVNxxxxxxxxxxxxxxxxxxxx` **покажут один раз**. Скопируйте его
сразу; закроете окно — придётся создавать новый (это не страшно).

> Названия кнопок в консоли иногда меняются. Ориентируйтесь на слова
> «Сервисные аккаунты», «Роль», «API-ключ» — сами разделы на месте.

---

## Часть 2. Пустить сессию в Яндекс

Дальше записываю я — вам остаётся отдать сессии ключ и открыть ей один
адрес. Обе настройки лежат в одном месте.

**2.1.** В заголовке этой сессии — меню окружения (там, где написано имя
окружения). Откройте его и выберите **Edit**.

**2.2. Сеть.** Найдите раздел **Network access**. Сейчас там политика,
которая режет всё лишнее — поэтому запросы к Яндексу и не проходили.
Выберите режим со списком разрешённых доменов и добавьте строкой:

```
tts.api.cloud.yandex.net
```

Это единственный адрес, который нужен: ключ API обменивать ни на что не
надо, запрос уходит прямо на синтез. Если поле просит домен целиком, а не
хост, подойдёт `api.cloud.yandex.net`.

**2.3. Ключ.** В том же окне найдите раздел для секретов — он может
называться **API credentials**, а если такого нет, то **Environment
variables**. Добавьте две переменные:

| Имя | Значение |
|---|---|
| `YANDEX_API_KEY` | ключ из пункта 1.6, целиком, начинается на `AQVN` |
| `YANDEX_FOLDER_ID` | идентификатор каталога из 1.4, начинается на `b1g` |

**Ключ не присылайте в переписку** — всё, что попадает в чат, остаётся в
его истории. Настройки окружения для того и сделаны.

**2.4.** Сохраните. Переменные подхватывает **новая** сессия, так что эту,
возможно, придётся перезапустить — ничего не потеряется, вся работа лежит
в репозитории, я продолжу с того же места.

**2.5.** Напишите мне «готово». Дальше я:

* прогоню образцы голосов и пришлю их вам — выберете, кто говорит за
  Искорку, зайчика, ёжика и лисёнка;
* запишу все 73 реплики;
* вставлю их в урок и пройду его заново с настоящими длительностями —
  сейчас кнопки и паузы рассчитаны на тишину.

## Безопасность

Разрешение открывает исходящие запросы контейнера на один адрес Яндекса и
доступа к вашему аккаунту не даёт — для синтеза всё равно нужен ключ.

Ключ же ограничен ролью: сервисный аккаунт с единственной ролью
`ai.speechkit-tts.user` умеет только синтезировать речь — ни читать, ни
удалять, ни создавать в облаке ничего. Поэтому худшее, что бывает при
утечке, — чужие расходы на озвучку. Закрывается двумя действиями:

* **Биллинг → бюджеты** — лимит, скажем, 300 ₽ с уведомлением. Нам нужно
  меньше двух.
* **Удалить ключ**, когда запишем. Одна кнопка; понадобится снова —
  создадите новый за минуту.

Не давайте этому сервисному аккаунту других ролей и не берите ключ от
аккаунта-владельца.

## Запасной вариант: записать у себя

Если пускать сессию в Яндекс не захочется, всё то же самое делается
скриптом на вашем компьютере — он самодостаточный, все реплики вписаны
в него.

**Python.** [python.org/downloads](https://www.python.org/downloads/) →
**Download Python** → в первом окне установщика **обязательно** галочка
внизу **«Add python.exe to PATH»**, потом **Install Now**. Проверка:
**Win+R** → `cmd` → `python --version`. Библиотек ставить не нужно.

**Запуск.** Положите `ozvuchka.py` в папку, например `C:\wowspeak`,
откройте Блокнотом и впишите своё внутрь кавычек:

```python
KEY = "AQVNxxxxxxxxxxxxxxxxxxxx"
FOLDER = "b1gxxxxxxxxxxxxxxxxx"
```

Дальше в командной строке:

```
cd C:\wowspeak
python ozvuchka.py obrazcy    образцы голосов в папку obrazcy
python ozvuchka.py            все 73 реплики в папку audio-4-6
python ozvuchka.py RU-05      переписать одну реплику
```

Голоса меняются в таблице `VOICES` в начале файла: слева герой, справа
голос и роль (`"good"` — доброжелательно, `"neutral"` — ровно, `None` —
без роли). Часть имён в режиме `obrazcy` скрипт пропустит с пометкой «нет
такого голоса» — список нарочно шире, какие голоса есть на самом деле,
видно только по ответу.

Готовую папку `audio-4-6` — в Google Drive, и напишите мне.

## Если что-то пошло не так (в запасном варианте)

| Что видно | Что это |
|---|---|
| `python не является внутренней...` | нет галочки «Add python.exe to PATH», переустановить Python |
| `Не вписаны KEY и FOLDER` | пустые кавычки в начале файла |
| `401` или `403` | ключ скопирован не целиком, либо сервисному аккаунту не выдана роль `ai.speechkit-tts.user`, либо каталог не тот |
| `Дорожка RU-07 не записалась: 400 ...` | пришлите мне текст ошибки целиком, это по моей части |
| Окно закрылось само | запускайте из командной строки (`cmd`), а не двойным щелчком |
| `Failed to establish a new connection` у меня в сессии | хост не попал в Network access либо сессию надо перезапустить |
