# «Расставь по местам»: подпись уходит в первый кружок, пока ребёнок его не выбрал

Нашла Анна 11.11.2026 (SM1 Unit 1 ДЗ 7, блок 3): «В таких заданиях сразу
выделен первый кружочек. Если нажать на любую фразу, она сразу встанет в этот
кружок. Нужно, чтобы ребёнок сначала нажал на кружок, и потом он выделился».

То же самое пришло заявкой от преподавателя 10.11: «не перетаскиваются слова
к картинкам, только если кликать по порядку следования картинок; если ребёнок
ошибается — нужно начинать выполнять всё заново».

## Причина

`src/public/homework/blocks.tsx`, `HotspotBlock`, функция `word(wi)`:

```ts
const word = (wi: number) => {
  if (!ctx.editable(id)) return
  const n = { ...a }
  let ix = u.pick
  if (ix === null || ix === undefined) {
    ix = pts.findIndex((_, i) => !n[i])            // ← вот это
    if (ix < 0) {
      ctx.toast('Сначала нажми точку на картинке')
      return
    }
  }
  n[ix] = bank[wi]?.text ?? ''
  u.pick = null
  ctx.set(id, n)
}
```

Когда кружок не выбран, подпись молча уходит в **первый свободный** кружок.
Ребёнок видит, что кружки заполняются по порядку, и воспринимает это как
«выбора нет». Подсказка под заданием при этом говорит другое: «Перетащи
подпись в кружок на картинке (или нажми кружок, потом подпись)».

## Что сделать

Убрать подстановку в первый свободный кружок: без выбранного кружка нажатие
на подпись ничего не ставит, а показывает ту же подсказку.

```ts
const word = (wi: number) => {
  if (!ctx.editable(id)) return
  const ix = u.pick
  if (ix === null || ix === undefined) {
    ctx.toast('Сначала нажми кружок на картинке')
    return
  }
  const n = { ...a }
  n[ix] = bank[wi]?.text ?? ''
  u.pick = null
  ctx.set(id, n)
}
```

Остальное не трогаем: нажатие на кружок уже выбирает его (`point`), повторное
нажатие снимает выбор, нажатие на заполненный кружок очищает его, а
перетаскивание подписи мышью и пальцем уже выложено 10.11.2026 (`dragProps`,
`dropOn`) и работает в любом порядке.

**По желанию, если будет время:** сделать выбор двусторонним — нажатие на
подпись, когда кружок не выбран, подсвечивает саму подпись, и следующий
нажатый кружок её принимает. Тогда ребёнку всё равно, с чего начинать. Это
больше кода, и без него задание уже работает правильно.

## Проверка

Открыть SM1 Unit 1 ДЗ 7, блок 3 «глазами ученика»:

1. до первого нажатия ни один кружок не подсвечен оранжевым (`.khm.sel`);
2. нажатие на фразу ничего не ставит, появляется подсказка;
3. нажали кружок → он подсветился → нажали фразу → она встала именно туда;
4. перетаскивание работает как было, в любом порядке;
5. нажатие на заполненный кружок очищает его.
