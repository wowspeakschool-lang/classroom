# Озвучка аудирований через Yandex SpeechKit

Библиотека подмен и скрипт озвучки. Решение Анны 10.11.2026: «запоминай, какие
слова он неправильно произносит и как лучше их писать… составляй библиотеку,
потом её юзай».

- `podmeny.json` — **библиотека подмен**: `[регулярка, как написать для синтеза]`.
  Подмена идёт только в текст, который уходит в синтез; в блоке и в документе
  текст не меняется. Новое плохо прочитанное слово — сразу сюда (и строкой в
  таблицу `docs/ozvuchka_speechkit.md`, где записано, *почему*).
- `ozvuchit.py` — озвучка: `python3 tools/speechkit/ozvuchit.py <zadanie.md> <папка> [имена файлов…]`.
  В `zadanie.md` блоки `Файл: \`name.mp3\`` и следом блок кода с текстом.
  Голос john, en-US, скорость 0.9, каждое предложение отдельно, пауза 1 с,
  2 с перед «Number N». Пишет `texts.json` для сверки.

Перед отправкой Анне — проверка распознавателем (faster-whisper `small.en`,
wav 16 кГц моно) целиком и по фразам; спорное — по спектру. Подробности и
история каждой подмены — `docs/ozvuchka_speechkit.md`.

Как писать подмену (что синтез понимает):
- ударение — `+` перед ударной гласной: `ge+ography`, `ba+nanas`;
- ЗАГЛАВНЫЕ и дефисы синтез читает по буквам — не использовать;
- SSML `phoneme` не использовать — добавляет лишние звуки;
- слово, которое плохо звучит только в конце фразы, — регулярка с
  `(?=[.!?]?$)`, чтобы не трогать его в середине;
- имя, которое звучит по-разному в начале и середине фраз, написанием не
  лечится — вклейка одного куска во все места (см. `docs/ozvuchka_speechkit.md`).
