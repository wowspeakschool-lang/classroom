# Задание: описания картинок для Spotlight 5 (тренажёр слов, ученики 10–11 лет)

Вход: `todo_K.json` — список слов {term, translation, deck, folder}. Выход: `sheets_K.py` в этой же папке.

Формат выхода (Python):
```python
S = [
 ('Название листа по-русски', 'Примечание к листу: кто на картинках, без текста и т. п.', [
  ('<term ровно как во входе>', '<подпись на листе>', '<что нарисовать, по-русски, одна фраза>'),
  ...
 ]),
 ...
]
```

Правила:
- Каждое слово из входа — ровно один раз, в порядке входа (лист = подряд идущие слова, по 9 на лист; последний лист может быть 6–10). Лист не обязан совпадать с колодой, но старайтесь резать по границам колод/тем.
- Подпись: английское слово/фраза как в учебнике, но без скобок с грамматикой ("child (pl: children)" → "child"; "do the/go shopping" → "go shopping"; длинная фраза — можно сократить до узнаваемого ядра, ≤ 4 слов). Подписи должны быть уникальны во ВСЁМ файле; если два слова дают одинаковую подпись (омонимы), добавьте уточнение в скобках: "mean (greedy)".
- Описание — конкретная сценка или предмет, понятный ребёнку без слов: кто, что делает, ключевая деталь. Для отвлечённых слов и фраз — ситуация, из которой смысл ясен (как "hope — мальчик скрестил пальцы и смотрит на падающую звезду"). Для чисел — НЕ цифры, а количество предметов не нужно: числа (eleven, twenty...) пометьте описанием "ЦИФРЫ" — их рисует скрипт.
- Мягко: без крови, ран, слёз, оружия, страшного. Никакого текста, букв, цифр внутри рисунка (кроме случаев, где это и есть смысл, тогда лучше обойти).
- Страны/города: узнаваемое место и маленький флаг страны на флагштоке; флаги — точно.
- Одно предложение, по-русски, до ~20 слов.

После записи проверьте скриптом: импорт `sheets_K.py` работает, все term входа присутствуют ровно по разу в том же порядке, подписи уникальны. Ответьте кратко: число листов и слов.
