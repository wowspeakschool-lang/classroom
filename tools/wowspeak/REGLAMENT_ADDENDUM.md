# WOW Speak — ДОПОЛНЕНИЕ К РЕГЛАМЕНТУ (что изменилось)

Этот файл идёт в комплекте с `HANDOFF.md`, `WORD_BANK.md`, `wowspeak_builder.py`,
`wowspeak_cropping.py` и — обязательно — `wowspeak_games.py` (без него игры не соберутся).

Файл не привязан к возрастам. Группы, уровни и структуру уроков бери из основного
регламента — здесь только то, что поменялось в способе работы.

## 1. Как со мной разговаривать

Просьбы и вопросы — **всегда первой строкой сообщения, помеченные 🟥**, до всего остального:

> 🟥 НУЖНО ОТ ВАС: ссылка на видео. Одна на все деки или разные.

Цветом в чате выделять нельзя — markdown этого не умеет. Поэтому маркер 🟥 (та же пометка,
что в заметках для учителя) плюс позиция наверху. Сообщения держать короткими: длинные
простыни не читаются, просьба в конце теряется.

## 2. Картинки — генерирую я, напрямую через OpenAI API

Коннектора GPT в списке инструментов нет и не будет — это не коннектор. Ключ лежит в
переменной окружения `OPENAI_API_KEY`, домен `api.openai.com` разрешён. Проверка:

```
curl -s -o /dev/null -w "%{http_code}\n" https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"      # → 200
```

Генерация: `model: gpt-image-1`, `size: "1536x1024"`, `quality: "high"`,
`background: "opaque"`. Ответ в base64 (`data[0].b64_json`).
→ `wowspeak_cropping.gen_sheet(words, out)`.

**НЕ использовать `background: "transparent"`** — нарезка и белые плитки рассчитаны на белый
фон, прозрачность съедает белые части персонажей.

Лист: ≤10 иконок, слова всех дек темы объединять (обычно хватает одного листа), никакого
текста на картинке, крупные белые промежутки.

Стиль — **ЯРЧЕ И КРАСОЧНЕЕ**. Приглушённая бежево-охристая гамма не подходит. В промпт
обязательно (константа `wowspeak_cropping.STYLE`):

> Style: bright, vivid, saturated children's cartoon illustration — playful and joyful.
> Use a RICH and VARIED colour palette: bright blues, greens, yellows, reds, purples and
> pinks together, not a single muted earth-tone scheme. High colour contrast between
> neighbouring shapes, cheerful sunny mood, soft rounded friendly shapes.
> Avoid beige, brown, ochre and washed-out desaturated colours.

Абстрактные слова описывать конкретной сценой и следить, чтобы соседние абстракции не
выглядели одинаково (chill / break / tired легко сливаются). Один плохой рисунок —
перегенерировать только его. Кривизну лечить перенарезкой.

**Нарезка — только `crop_grid_auto`, не `crop_grid`.** Старый `crop_grid` делит лист на
равные колонки, а GPT раскладывает картинки неровно — равные колонки режут объекты пополам.
Порядок: `whiten(sheet)` → `crop_grid_auto(...)`. `whiten` нужен потому, что фон GPT кремовый
(254, 253, 248), а не белый, и на белой плитке проступает квадрат. `crop_grid_auto` находит
сами объекты, группирует по близости центров (мяч остаётся с мальчиком, двое в одной сцене
не разъезжаются) и затирает белым всё чужое, что попало в кадр.

**Превью обязательно** — собрать монтаж (`preview`) и ждать «ок».

## 3. Видео — ищу я

**Видео всегда одно на все четыре презентации**, не разное по версиям. Длина — **не больше
~4 минут**. Отдаю 2-3 кандидата с названием и каналом, выбираешь ты.

Ограничение: страницы YouTube из этой среды могут быть недоступны — тогда названия беру из
поисковой выдачи, длину и содержание не проверяю, и честно об этом пишу.

Скачивать ролики не буду — нарушает правила YouTube. Нужен офлайн — пришли свой видеофайл,
встрою прямо в слайд (`add_movie`, `cfg['video_file']`).

Ссылку вешать **на фигуру кнопки** (`shape.click_action.hyperlink.address`), а не на
текстовый run: иначе редакторы перекрашивают надпись в синий с подчёркиванием и кликабелен
только текст.

## 4. Игры — внутри .pptx, WordWall не используем

WordWall убран совсем, файл со словами колонкой под него больше не нужен. Игры собираются
модулем `wowspeak_games.py`, работают без интернета, аккаунтов и ссылок.

| Функция | Что делает |
|---|---|
| `g_quiz_series` | серия раундов «выбери правильную картинку» |
| `g_missing_pics` | «что пропало» — карточка исчезает по-настоящему. По умолчанию каждый шаг = свой слайд (работает везде), `anim=True` — одним слайдом через `<p:timing>` |
| `g_reveal` | ответы появляются по одному щелчку |
| `g_board` | кликабельная доска: номер → вопрос → назад |
| `g_quiz` / `g_missing_anim` | то же, но на эмодзи, без иконок |

Под этим два механизма: переходы между слайдами гиперссылками (работают везде) и штатные
анимации PowerPoint «Появление / Исчезание по щелчку», вписанные в XML слайда как `<p:timing>`.

### ПРАВИЛА — нарушать нельзя, всё выстрадано

1. **Одна карточка = одна фигура, текст ВНУТРИ фигуры.** Не класть надпись поверх кнопки:
   надпись перехватывает клик и центр кнопки мёртвый (попасть можно только по узкой рамке),
   а анимированная карточка из трёх объектов исчезает за три щелчка вместо одного.
   Использовать `btn()` / `card_text()`, не `rect()` + `text()`. Картинку сверху класть
   можно, но ей нужна та же ссылка, а для анимации карточка и картинка передаются одной
   группой (`media_on()` возвращает список — это и есть группа).
2. **Задание должно быть логичным — подписи не выдают ответ.** Если под картинкой написано
   `pet`, вопрос «Which one is "pet"?» проверяет чтение, а не знание слова. Подписи есть
   только на обучающем слайде New Words; в квизе, «что пропало» и Point & Race их нет.
   Эмодзи из вопроса тоже убрать: «Which one is "pet"? 🐶» — собачка и есть ответ.
3. **Задание — на ВСЕ слова урока**, а не на одно. Игра заменяет WordWall, а WordWall
   спрашивает всю лексику. Значит один раунд на каждое слово: правильно → следующее слово,
   ошибка → тот же вопрос. В углу счётчик 1/6 … 6/6, в конце слайд-финал.
4. **Правильный ответ не должен идти по порядку** — позиция 1-2-3-4 подряд считывается за
   два раунда. Использовать `(k*3) % nopt`.
5. **Клик мимо кнопки не должен листать слайд.** На квизе и доске вызывать
   `no_click_advance()` — иначе случайный тык по фону перескакивает сразу на «YES! Correct!»
   и портит ответ.
   *Уточнение после теста в PowerPoint:* сделано это НЕ через `<p:transition advClick="0">`,
   а невидимой фигурой-ловушкой на весь слайд с действием «ppaction://noaction». Выключатель
   в переходе гасит и те клики, которых учитель ждёт, — слайд выглядит зависшим. Плюс
   маленькая «→» в левом нижнем углу (встроенное действие «следующий слайд»), чтобы с такого
   слайда всегда был выход мышкой, а не только стрелкой на клавиатуре.
6. **Служебные слайды — в конец файла** через `finish(p, helpers)`. Иначе, листая урок
   стрелками, учитель упирается в «Correct / Try again» посреди занятия.
7. **Экраны обратной связи возвращают по клику в любую точку** (`link_whole_slide`) —
   целиться в кнопку не нужно.
8. **Цвет карточки не должен совпадать с фоном слайда.** В `B.PASTELS` лежат ровно те цвета,
   что используются как фоны, поэтому `PASTELS[i % 6]` рано или поздно выдаёт цвет фона и
   карточка становится невидимой. Использовать `pal(bgc, i)`. В старых деках этот баг виден:
   в осенней теме терялась карточка «walk».
9. **Заметки для учителя переписывать под игры**: номера слайдов, что игры работают только в
   режиме показа (F5), что клик мимо кнопки не листает, и что подписи убраны намеренно —
   иначе это примут за баг. (Билдер подставляет живые номера через `{GAMES}`, `{VIDEO}`,
   `{SPEAKING}`, `{SERVICE}`.)
10. **Длина деки вырастет.** Раунд на каждое слово — это +N слайдов. Если урок не влезает,
    сокращать осознанно: раунды только на новые или трудные слова.

## 5. Мелочи, которые лучше поправить сразу

- `s_title` и `s_farewell` в билдере содержали 🎃 — наследие Хэллоуина, ехало во все темы
  подряд. Теперь эмодзи берутся только из `cfg['emoji']`.
- `save()` копировал в `/mnt/user-data/outputs/` — в Claude Code такой папки нет. Сохранять
  через `p.save(path)` и отдавать файлы прямо в чат.
- LibreOffice Impress для рендер-QA может быть не установлен:
  `apt-get install -y libreoffice-impress`, дальше `soffice --convert-to pdf` и PyMuPDF для
  картинок. Анимации в PDF не проигрываются — проверка самих игр всегда на твоей стороне,
  в настоящем PowerPoint.
- Банк слов: повторы отдельных слов — нормально. Нельзя, чтобы два урока были про одно и то
  же и списки почти совпадали (два урока про одежду). Один предмет одежды, выпавший в другой
  теме, — не страшно.
- После сборки прогонять двойной round-trip (открыть-сохранить дважды) и проверять, что
  анимации и переходы на месте → `wowspeak_qa.py`.
