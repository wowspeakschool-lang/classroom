# Classroom — LMS школы wowspeakschool

Статический сайт (GitHub Pages, домен `classroom.wowteach.ru`) + база в Supabase.
`index.html` — редактор уроков для учителя, всё приложение в одном файле.

## База

Проект Supabase `vtcxghsqymwkyiogpndf`. Иерархия:

```
classroom_courses → classroom_units → classroom_lessons → classroom_blocks
```

`classroom_blocks (lesson_id, type, payload jsonb, sort_order)`, уникальный ключ
`(lesson_id, sort_order)` — на нём держится идемпотентность миграций.

Колонки `classroom_lessons`, о которых легко забыть:

| колонка | значения |
|---|---|
| `kind` | `homework` · `test` · `lesson`. По умолчанию `homework`. **Тест без `kind='test'` ляжет обычной домашкой.** |
| `pass_threshold` | домашки 60, тесты 90 |
| `is_published` | заливать **всегда `false`**, включает методист вручную |
| `sort_order` | задавать числом явно, не `max+1` |

15 типов блоков: `text · video · quiz · exact_input · match · task · embed · order ·
sort · flashcards · gaps · truefalse · speaking · sequence · hotspot`.
Точные поля payload смотреть в `index.html` — там и рендер, и редактор.

## Картинки

Лежат в `media/` этого репозитория, отдаются с `https://classroom.wowteach.ru/media/`.

```
media/shared/     приветствия, похвалы, 👍/👎 — общие для всех юнитов
media/sm2/u1/     картинки юнита
```

**Только ссылки, никогда base64.** Байты картинок обрабатываются скриптами и не
попадают в текст ответа — вписать base64 в SQL значит воспроизвести десятки тысяч
случайных символов по памяти, то есть тихо испортить одну-две картинки.
Разница на практике: строка урока 9 КБ вместо 67 КБ.

В миграции путь собирается через плейсхолдер:

```sql
v_media text := 'https://classroom.wowteach.ru/media/';
...
(v_lesson, 'match', replace($blk${"pairs": [{"left_image": "@@MEDIA@@sm2/u1/chair.webp",
  "right": "chair"}]}$blk$, '@@MEDIA@@', v_media)::jsonb, 6)
```

Размеры: карточка 180–420 px, сцена 760–900 px, служебные 200 px. Формат webp,
качество 88 для карточек с мелким текстом, 78–82 для объектов и фото.

## Озвучка

Рядом с пустым полем `audio` кладётся ключ с суффиксом `_tts`:

```json
{ "text": "get up", "audio_tts": "get up" }
```

Кнопка «Озвучить пачкой» находит такие пары на любой глубине, синтезирует и
заполняет `audio`. Уже заполненный звук не трогается. Значение — строка или
`{text, voice}`. Мы только размечаем, нажимает методист.

## Перенос ДЗ из PDF-выгрузки «Взнания»

Полная инструкция — в документах методиста. Здесь то, на чём уже спотыкались.

**«Пустой» блок в выгрузке обычно не пустой.** В Unit 1 четыре заполненных
задания были приняты за пустые, потому что извлечённый текст ничего не показал.
Каждый «Открытый вопрос» и каждый блок без текста открывать картинкой страницы
и смотреть глазами.

**«Открытый вопрос» — это блок `task`, а не `text`.** Текстом ученику некуда
вписать ответ.

**Правильный ответ виден только при увеличении.** Отмечен тот вариант, у которого
**нет** пустого чекбокса. На целой странице чекбокс — несколько пикселей: вырезать
область с вариантами и увеличивать.

**Галерея фонов лежит только после блока «Выберите новое задание для урока».**
Её размер 900×506 — ровно как у обучающих карточек методиста. По размеру не
фильтровать, иначе теряются карточки с лексикой и грамматикой.

**Игры Wordwall.** Содержимого в выгрузке нет никогда. Тип и название видны на
обложке — этого хватает, чтобы пересобрать игру штатным блоком. Обложка пустая —
собирать по материалу того же урока. В обоих случаях помечать «СОСТАВ МОЙ» и
выносить строкой в файл «доработать руками».

**Нумерация блоков.** В редакторе блоки показаны с 1, а `sort_order` начинается
с 0. В файле для методиста писать номер **как в редакторе** (`sort_order + 1`),
иначе она откроет соседний блок.

**Картинки, вставленные в чат, а не приложенные файлом.** На диск они не
попадают, но лежат в транскрипте сессии
`~/.claude/projects/<проект>/<session-id>.jsonl` — блок `{"type":"image"}` с
`source.data` в base64. Обходить дерево рекурсивно: у вставленной картинки блок
в `message.content[]`, у открытой инструментом — глубже, в результате вызова.
**Картинки из сообщения, присланного посреди хода**, лежат иначе: запись
`{"type":"attachment"}`, путь `attachment.prompt[]`, роли `user` у неё нет —
обход только по `message.role=="user"` их не находит. И в транскрипт они
попадают не сразу: пока ход не закончился, их там ещё нет.

**Генерация картинок.** Ключ OpenAI в `OPENAI_API_KEY`, модель `gpt-image-1-mini`,
качество `medium`. Стиль — 3D-рендер как в программе. В промпте обязательны
«plain flat pure white background», «no shadow on the background» и требование
поля по краям: генератор любит упирать фигуры в край и обрезать их. После
генерации проверять долю не-белых пикселей вдоль каждой стороны.

## Проверка перед заливкой — обязательный шаг

Payload разбирается скриптом до применения миграции:

1. `correct` указывает на задуманный вариант;
2. нет дублей среди вариантов одного вопроса;
3. правые значения в `match` уникальны (иначе блок надо менять на `quiz`);
4. в `order` склейка `words` совпадает с `sentence` — ловит разные апострофы;
5. число пропусков в `gaps` совпадает с задуманным (`__[^_]+__`);
6. каждая ссылка `@@MEDIA@@…` соответствует существующему файлу в `media/`.

После заливки — контрольный `select`: число блоков, типы, отсутствие оставшихся
`@@MEDIA@@`.

## Git

Работаем в `main`, пушим сразу — контейнер сессии временный, незакоммиченное
пропадает вместе с ним. По той же причине настройки лежат в `.claude/settings.json`
(коммитится), а не в `settings.local.json`.

# Лид-магнит WowSpeak «Волшебная страна»

Второе направление в этом же репозитории, с базой и юнитами не связано.
Мини-курс из 4 уроков + карта-хаб. ТЗ: `docs/WowSpeak_карта_ТЗ.md`,
исходный хендовер: `docs/WowSpeak_HANDOFF.md`. Ветка `claude/charming-volta-8wralr`.

## Что где лежит

| Путь | Что |
|---|---|
| `wowspeak.html` | **готовый лид-магнит одним файлом**: карта + 4 урока внутри |
| `map.html` | карта-хаб отдельной страницей, из неё собирается единый файл |
| `lessons/wowspeak-mini/lesson-1..4.html` | уроки, самодостаточные HTML |
| `assets/map/`, `assets/items/`, `assets/teacher/` | мастера картинок PNG, `web/` — сжатые WebP |
| `tools/` | генерация, сжатие, правка уроков, сборка |

## Главное правило: уроки правятся скриптами, не руками

Каждая правка уроков — отдельный скрипт в `tools/`, применяемый ко всем четырём
файлам одинаково. Руками в 6-мегабайтном HTML делать нечего.

```
tools/add_map_story.py        сюжетные экраны входа/выхода, прогресс, кнопка «на карту»
tools/make_lessons_responsive.py  поведение на больших экранах
tools/theme_lessons_bright.py     яркая тема
tools/embed_teacher.py            портреты Хранительницы
tools/rework_rewards.py           награды — волшебные предметы
tools/embed_lesson_images.py N    вставка картинок из assets/lesson-N/
tools/sync_shared_images.py       общие картинки урока 1 → уроки 2-4
tools/make_fragments.py           кусочки одежды для угадайки (режутся из урока 1)
tools/recolor_lesson4.py          одежда фигурки урока 4 под наш комплект цветов
tools/gen_avatar_figures.py       8 сочетаний одежды на каждый пол (генерация, платно)
tools/embed_avatar_figures.py     фигурки в одевалку урока 4 + переход на целые картинки
tools/embed_avatars.py            дети-аватары av1-av8 из assets/avatars/ в уроки 2-4
tools/render_key_svg.py           запасной ключик из векторной фигуры карты
tools/embed_story_pictures.py     острова и ключик на сюжетные экраны вместо эмодзи
tools/fix_texts.py                правки реплик: награды, прощания, финал курса
tools/three_keys.py               три ключика вместо четырёх (карта + выход Урока 4)
tools/fix_end_buttons.py          кнопки финала: карта — на табличке «Урок завершён»
tools/add_star_hint.py            звёздочка-подсказка в анаграмме Урока 1
tools/make_task_optional.py       «Пропустить» у второго письменного задания У3
tools/polish_ui.py                кусочек в окошке, силуэты в рюкзаке, счётчик, задержки
tools/prune_dead_images.py        выкидывает картинки, на которые никто не ссылается
tools/dev_arrows.py [--off]       ВРЕМЕННАЯ панель: стрелки + «начать сначала»
tools/build_single_file.py        сборка wowspeak.html
```

Порядок применения при пересборке с нуля: `git checkout -- lessons/`, затем
скрипты в порядке списка, затем сборка. `embed_avatar_figures.py` обязательно
до `prune_dead_images.py`: он убирает из кода ссылки на старые плоские слои,
и только после этого их можно выкинуть. **Скрипты обязаны быть переприменяемыми** —
дважды на этом обожглись: скрипт видел свою метку, молча пропускал файл, и правки
не доезжали.

## 🟥 Перед публикацией: убрать панель просмотра

`python3 tools/dev_arrows.py --off` и пересобрать. Панель стоит и в уроках,
и на карте: стрелки по экранам и кнопка «начать сначала», которая чистит
`wowspeak_journey` и `wowspeak_lessonN_progress`. Пока она включена, ребёнок
пролистает урок мимо заданий.

## Ловушки, на которых уже спотыкались

**В едином файле панелей две — карты и урока, и они в одном месте.** Урок
открывается в iframe поверх карты, но панель карты лежит выше него и закрывала
собой стрелку «вперёд». Пока урок открыт, панель карты прячется правилом
`body.in-lesson #wsdev-nav{display:none}` — у урока своя панель с тем же сбросом.

**`#dev-nav` уже занят вёрсткой уроков 2-4.** Там лежит правило
`#dev-nav { left:12px }` от прежней панели разработчика, и наша панель с таким же
именем уезжала за левый край — кнопка «назад» была не видна, хотя в коде она была.
Поэтому имена начинаются с `wsdev-`.

**Литерал закрывающего тега скрипта обрывает скрипт** — даже внутри строки или
комментария. Сборщик единого файла экранирует их и проверяет число закрывающих
тегов.

**`.continue-area::before`** — белая подложка шириной `100vw` под кнопкой «Дальше»
из исходной вёрстки урока. На ярком фоне режет экран полосой. Отключена в теме.
Псевдоэлемент с `z-index:-1` не находится ни `elementFromPoint`, ни перебором
элементов — искать только чтением CSS.

**Картинка награды подбирается по эмодзи**, а не по имени файла: таблица
`EMOJI_KEY`. Меняете награду — меняйте и её.

**Индекс `screenById` строится до `linearOrder`.** Дописали экран — перестройте
индекс, иначе `currentScreen()` вернёт `undefined`.

**Счётчик прогресса в Уроке 1 захардкожен** (`total: 24`) с поправкой на развилку
`2-2A/2-2B`. В уроках 2–4 считается от длины массива.

**Картинки уроков 2-4 берутся из урока 1, а не генерируются заново.** Общие
(Хранительница, предметы, одежда) переносит `sync_shared_images.py`, кусочки для
угадайки режет `make_fragments.py`. Генерация тех же вещей заново разводит цвета:
кепка на кусочке была красной, а в уроке фиолетовой.

**Перекраска картинок — сдвиг тона, и сохранять надо без потерь.** При лоссовом
webp по краю перекрашенного пятна каждый раз появляются пиксели прежнего
оттенка, и повторный прогон красит их снова — скрипт перестаёт быть
переприменяемым.

**Одевалка Урока 4 — не слои, а восемь готовых картинок на пол.** Объёмные слои
не сводятся: генератор не повторяет позу пиксель в пиксель, и на фигурке
разъезжаются шея и пояс. Поэтому рисуем фигурку целиком в каждом сочетании
(кепка × куртка × шорты), ключи `fig_<пол>_<кепка><куртка><шорты>`. Каждое
сочетание делается **одной** правкой базовой картинки, а не цепочкой правок:
на второй-третьей правке у ребёнка плывут кожа, глаза и цвет обуви.

**Мастера фигурок лежат в webp, а не png.** Картинка 1024×1536 в png весит
2.4 МБ, в webp — 0.24 МБ, а `/v1/images/edits` webp принимает.

**Состав одежды у av1-av8 менять нельзя.** Задания проверяют ответ по таблице
`AVATARS` (`has: [...]`), а не по картинке: лишняя куртка на av2 ломает задание
«I haven't got a jacket». У av4 и av5 состав одинаковый — это разные дети, они
стоят рядом в одном задании.

**Белый фон с генератора режется в два прохода.** Заливка от краёв не достаёт
до дырок внутри предмета: у ключика внутри кольца оставалось белое пятно.
Второй проход чистит замкнутые белые области крупнее 0.3% картинки — блики на
золоте желтоватые и под порог не попадают.

**Сюжетные экраны рисовали эмодзи, а не картинку.** Экран входа показывал
🎪 / 🪞 / 👫 / 🏰, экран награды — 🔑, и это легко пропустить: эмодзи в 96 px
издали похоже на иконку. Теперь `embed_story_pictures.py` кладёт в урок остров
(тот же, что на карте) и ключик, а рисовалка идёт через `picNode`, который берёт
картинку по таблице `EMOJI_KEY`. Добавляете экран с картинкой — проверьте, что
эмодзи есть в этой таблице, иначе ребёнок увидит символ вместо рисунка.

**Награды в текстах отставали от сюжета.** В Уроках 2 и 3 в табличке финала и
в вариантах рефлексии оставались «меч» и «медаль» из прежней версии, хотя дают
сапоги-скороходы и колокольчик. Меняете награду — ищите её упоминания во всех
текстах урока, а не только на экране выдачи.

**Кнопка «Вернуться на карту» живёт на табличке «Урок завершён», а не на
прощании.** На прощании две кнопки: «Пройти урок ещё раз» и «Завершить урок».
Возврат идёт через `goToMap()`, который сам отличает iframe единого файла от
отдельной страницы, поэтому сборщику подменять кнопку больше не нужно.

**`PROJECT_ACH` в Уроке 4** — список наград для финального проекта. Меняете
награды — меняйте и его.

## Картинки

Мастера PNG в `assets/`, для страниц — WebP через `tools/optimize_web_assets.py`.
Генератор отдаёт максимум **1536 px** по длинной стороне, поэтому фон на весь
экран всегда чуть мягче родного разрешения; для широких экранов лежит отдельная
горизонтальная картинка.

**Стоимость.** 1536×1024: `low` ~$0.016, `medium` ~$0.063, `high` ~$0.25.
Гоняем промпт в `--draft` (low), пока содержание не сойдётся, потом один прогон
в medium. Несоответствия промпту — пропавшая юбка, буквы на компасе — видны и
в черновике. Первый комплект стоил ~$3.4 вместо ~$0.55 именно из-за этого.

**Промпты для генерации Анной** — `docs/WowSpeak_промпты_урок1.md`,
`docs/WowSpeak_промпты_аватары.md` (дети av1-av8). Главное:
прикреплять образец стиля картинкой, иначе слова про «cartoon» перебиваются
словами про строчку и карманы, и выходит товарный рендер для маркетплейса.

# Лид-магнит 4–6 «Дорога на праздник»

Версия для тех, кто ещё не читает. Три острова, гид — светлячок **Искорка**.

| Остров | Учим | Повторяем |
|---|---|---|
| Солнечная Полянка | `green` · `blue` · `yellow` | — |
| Облачный | `a top` · `jeans` · `shoes` | цвета, потом цвет **вместе** с одеждой |
| Драконий | фраза `I have a green top` | всё вперемешку |

Три правила, на которых держится содержание:

* **Накопление.** Новое слово → задания только на него → следующее слово →
  задания на оба → третье → на все три.
* **Повторение впереди нового.** Уроки 2 и 3 начинаются с трёх коротких
  заданий по прошлому материалу, до первого нового слова.
* **Слияние.** Как только одежда отработана, идут задания на цвет вместе с
  вещью: «a green top», а не «a top».

## Три файла

```
tools/kids46_lessons.py   содержание: слова, задания, реплики
tools/kids46_page.html    вёрстка и движок
tools/build_kids46.py     сборка
      ↓ python3 tools/build_kids46.py
wowspeak-4-6.html                (~2.7 МБ)
docs/WowSpeak_озвучка_4-6.md     что озвучивать
```

**Вещь на экране — это пара `(предмет, цвет)`**, картинка берётся по ключу
`предмет_цвет`. Что при этом звучит, решает поле `say`: `color` → «green»,
`item` → «a top», `combo` → «a green top», `sentence` → «I have a green top».
Одна пара даёт четыре разных задания, поэтому и уроки, и файл озвучки
собираются из одного списка.

Типы заданий: `word · findall · sort · order · name · collect · catch ·
pick · fingers`. `collect` — это и чемодан, и магазин, и стирка: меняется
только картинка цели.

## Цвета делает скрипт, а не генератор

`tools/recolor.py` красит **только господствующий цвет предмета**. Простой
сдвиг тона делает машинку одноцветной: синие стёкла и жёлтые фары красятся
вместе с кузовом, у цветка — зелёный стебель. Сейчас у рыбки остаётся карий
глаз, у ботинок белая подошва, у джинсов жёлтая строчка.

Красить скриптом важно не ради экономии: если зелёный на шарике, на топе и
на кляксе будет разным, на уроке цветов ребёнок запутается.

Подготовленные картинки лежат в `tools/.kids46_images.json` (в git не идёт).
Без кэша пересборка занимает две с половиной минуты.

## Рука с пальцами

Фразу показываем finger method: рука с числом пальцев по числу слов, стрелка
прыгает по кончикам в такт. Сначала ребёнок слышит и следит, потом стрелка
идёт молча — и он говорит сам. Кнопка «Ещё раз» повторяет.

Координаты кончиков — `FINGER_TIPS` в сборщике, в долях от рамки фигуры.
**Автоматически они не ловятся**: большой палец торчит вбок и по верхнему
контуру не находится. Сняты по сетке руками; картинки не меняются, так что
это разовая работа.

На той же руке идут три дрилла: `chain` (фраза растёт), `back` (собирается
с конца), `swap` (меняется одно слово, картинка на глазах перекрашивается).

## Озвучка

Дорожки в `assets/audio-4-6/`: `RU-01.mp3`, `EN-01.mp3`, `EN-01-slow.mp3`.
Тексты и интонации — `docs/WowSpeak_озвучка_4-6.md`, он собирается вместе с
уроком, поэтому разойтись с ним не может. **После записи порядок экранов не
менять** — номера сдвинутся; добавлять только в конец.

**Русский синтез браузера не используем** — звучит плохо. Без записи реплика
молчит, текст для взрослого остаётся в пузыре. Английские слова синтез
читает. На ответ звучат короткие сигналы — `tone_wav()` собирает WAV в сборке.

## Ловушки

**Размер элемента нельзя задавать одной высотой.** Корзины и кляксы были
`height:100%`, ширина бралась из пропорций картинки — три штуки не влезали в
ряд и уезжали за край экрана, нажать по ним было нельзя. Ряд должен делиться
поровну (`flex:1 1 0; min-width:0`), а картинка вписываться в свою долю. На
этом же спотыкались карточки: их сторона считается от реального размера ряда
через `--bw/--bh`, а не в `vh`.

**Таймер «показать Дальше» переживает смену экрана.** Сюжетный экран открывал
кнопку через две секунды, экран успевал смениться на задание — и ребёнок мог
пролистать задание мимо. Любой отложенный показ сверяется с маркером
отрисовки (`showNextLater`).

**У `play()` обязателен таймаут.** Событие «речь закончилась» в вебвью и на
телефоне может не прийти вовсе — без страховки урок встаёт намертво.

**Фон вырезается по «светлый И бесцветный».** Фон генератора строго серый, а
белые места самих картинок тонированные. Заливка по яркости уходила внутрь
облака и выедала 19% картинки.

**Картинки вшиваются вдвое крупнее самого большого места показа.** Впритык —
и на экране они мыльные. Проверка сравнивает натуральный размер с показанным.

**Панель просмотра сейчас включена** — `DEV_PANEL = True` в начале сборщика.
🟥 Перед публикацией поставить `False` и пересобрать.

## Проверка

Скрипт проверки живёт в scratchpad сессии: обходит все 97 экранов (с
раундами) на четырёх размерах, сам решает каждое задание, смотрит
переполнение, битые и растянутые картинки, ошибки консоли и границы карты.
Ссылка `?fast=1` ускоряет стрелку — иначе обход дриллов идёт минутами.
Синтез речи и проигрывание звука в headless подменяются заглушками.
