# a и an — маленькие слова перед предметами (Spotlight 3, Module 4)

Материал для видео. Зрители — дети 8–9 лет, 3 класс, учебник Spotlight 3, модуль 4 «Come in and play!» (игрушки).
Объяснение по-русски, английские слова и примеры — по-английски, чётко и медленно.

## Что ребёнок должен понять после видео

1. Перед **одним** предметом в английском ставим маленькое слово **a** или **an**. По-русски его не переводим — оно просто значит «один, какой-то».
   - a ball — мяч (один)
   - a doll — кукла
   - an apple — яблоко
2. **a** — если слово начинается с согласного звука: **a** ball, **a** doll, **a** kite, **a** robot, **a** teddy bear, **a** pencil case.
3. **an** — если слово начинается с гласного звука **a, e, i, o, u**: **an** apple, **an** elephant, **an** egg, **an** orange, **an** umbrella, **an** aeroplane, **an** octopus.
   - Почему? Попробуй сказать «a apple» — язык спотыкается: «а-эпл». С **an** звучит гладко: «эн-эпл». Буква **n** — как мостик между двумя гласными.
4. **a / an — только когда предмет ОДИН.** Если предметов много, a/an не ставим:
   - a ball → two balls, three balls
   - an apple → five apples
   - ❌ a balls ✅ balls
5. **a / an — только с тем, что можно посчитать.** Мяч, яблоко, кукла — считаются: один, два, три. А вот молоко, вода, хлеб — не считаются поштучно, поэтому НЕ говорим ❌ a milk, ❌ a water. Для них есть слово **some** — вы его уже знаете (модуль 3): some milk, some water.

## Частые ошибки (и как их поймать)

| Ошибка | Как правильно | Почему |
|---|---|---|
| a apple | **an** apple | apple начинается с гласной a |
| an ball | **a** ball | ball начинается с согласной b |
| a dolls | dolls / **a** doll | a — только для одного предмета |
| a milk | some milk | молоко не считают поштучно |

## Мини-игра для конца видео (с паузами на ответ)

Скажи: **a** или **an**?
1. ___ robot → **a** robot
2. ___ egg → **an** egg
3. ___ kite → **a** kite
4. ___ umbrella → **an** umbrella
5. ___ teddy bear → **a** teddy bear
6. ___ elephant → **an** elephant

Найди ошибку:
- I've got **a** cars. → I've got **a car**. / I've got **cars**.
- It's **a** orange. → It's **an** orange.

## Коротко (памятка)

- **a** + согласный звук: a ball, a doll
- **an** + гласный звук (a, e, i, o, u): an apple, an egg
- Только **один** предмет: a ball, но two balls
- Только то, что **можно посчитать**: ❌ a milk → ✅ some milk

## Для учителя (в видео не нужно)

В учебнике правило дано по букве (согласная / гласная). Слова-исключения по звуку (an hour, a uniform) в 3 классе не даём — в примерах их нет специально. Артикль the в модуле не изучается.
