# Паспорт проекта «Олимпиада по английскому языку Spotlight»

Пилотный поток · 5–9 классы · январь 2027 · черновик от 20.11.2026

## 1. Что и зачем

- **Что:** внутренняя онлайн-олимпиада школы по английскому языку по учебникам Spotlight.
- **Для кого:** ученики школы 5–9 классов. Пройти могут и те, кто у нас не учится.
- **Когда:** вторая половина января 2027 года, итоги до 31 января.
- **Где:** платформа школы app.wowteach.ru, из дома.
- **Зачем:** признание для учеников, интерес к языку и культуре, пробный запуск формата, знакомство новых детей со школой.

## 2. Что решено

- Отдельный комплект заданий на каждый класс: 5, 6, 7, 8, 9.
- Онлайн из дома. Олимпиада открыта 1–2 дня, на прохождение — таймер, попытка одна.
- Без созвонов, без апелляций и без показа работ.
- После закрытия олимпиады ученик видит в кабинете свои ответы, ошибки и правильные ответы.
- Материал — только пройденный по Spotlight: прошлые классы целиком и текущий учебник примерно до половины (модули 1–5 в 5–7 классах, 1–4 в 8–9 классах).
- Ориентир — Всероссийская олимпиада школьников, в облегчённом виде.
- Награды: 1, 2 и 3 места в каждом классе, сертификат участника каждому.
- Список призёров — имя и первая буква фамилии («Маша К., 6 класс»).

## 3. Разделы

| раздел | классы | проверка |
|---|---|---|
| Аудирование | 5–9 | автоматически |
| Чтение | 5–9 | автоматически |
| Лексика и грамматика (Use of English) | 5–9 | автоматически |
| Страноведение: культура, история, символы (Big Ben, флаги) | 5–9 | автоматически |
| Письмо — объём по нормам учебника для класса | 5–9 | человек — **вопрос 4.2** |
| Устная часть — запись ответа на платформе | 7–9 | человек — **вопрос 4.2** |

**Время.** Задания рассчитаны на 40 минут в 5–6 классах и на 60 минут в 7–9 классах. Таймер — на 15–20 минут больше, с запасом.

## 4. На обсуждение

### 4.1. Один тур или два

**Предложение методиста: один тур.** Поток первый, пробный. Отбирать участников незачем, и один тур надёжно укладывается в январь.

**Вариант — два тура**, как у онлайн-олимпиады Учи.ру: первый тур для всех, во второй проходят лучшие.

| | один тур | два тура |
|---|---|---|
| сроки | вторая половина января | I тур 11–17 января, II тур — конец января |
| плюсы | просто, меньше нагрузки, меньше риск не успеть | азарт «я в финале»; устную часть можно дать только финалистам |
| минусы | меньше «события» | вдвое больше заданий, плотные сроки после каникул |

### 4.2. Задания, которые проверяет человек

- **а) Письмо и устная часть.** Полная версия, нужна проверка учителями.
- **б) Только письмо.** Ученик печатает текст на платформе. Claude предварительно проверяет его по критериям, методист утверждает. Учителя не нужны.
- **в) Ничего.** Проверка полностью автоматическая.

### 4.3. Участники не из школы

- Ученик делится ссылкой, друг проходит олимпиаду наравне со всеми.
- **Идея:** вход через короткую регистрацию. Тогда школа видит, кто пришёл со стороны, и может пригласить ребёнка учиться.
- Нужно согласие родителей на обработку данных и на связь со школой. Уточнить с юристом.

## 6. Риски

| риск | что делаем |
|---|---|
| На платформе нет таймера, окна по времени или показа ответов после закрытия | проверить заранее, при необходимости — доработка платформы |
| Списывание дома | таймер, одна попытка, перемешанный порядок заданий, короткое окно |
| Ученики прошли по Spotlight разный объём | последний модуль — только лексика, основа — прошлые классы |
| Технический сбой у ребёнка | инструкция для родителей, контакт поддержки на время олимпиады |
