# Паспорт проекта «Олимпиада по английскому языку Spotlight»

Пилотный поток · 5–9 классы · январь 2027 · версия от 24.11.2026

## 1. Что и зачем

- **Что:** онлайн-олимпиада школы по английскому языку по учебникам Spotlight.
- **Для кого:** ученики школы 5–9 классов. Пройти могут и гости — дети, которые у нас не учатся.
- **Когда:** январь 2027 года, точные даты — после готовности заданий.
- **Где:** отдельный поддомен сайта wowspeak. Мы готовим страницы олимпиады в HTML, команда сайта их выкладывает.
- **Зачем:** признание для учеников, интерес к языку и культуре, пробный запуск формата, знакомство новых детей со школой.

## 2. Что решено

- **Один тур.**
- Отдельный комплект заданий на каждый класс: 5, 6, 7, 8, 9.
- **Материал — весь учебник Spotlight своего класса** за год (5 класс — весь Spotlight 5).
- Онлайн из дома. Олимпиада открыта 1–2 дня, на прохождение — таймер, попытка одна.
- Без созвонов, без апелляций и без показа работ.
- После закрытия олимпиады ученик видит свои ответы, ошибки и правильные ответы.
- Ориентир — Всероссийская олимпиада школьников, в облегчённом виде.

## 3. Разделы

| раздел | классы | проверка |
|---|---|---|
| Аудирование | 5–9 | автоматически |
| Чтение | 5–9 | автоматически |
| Лексика и грамматика (Use of English) | 5–9 | автоматически |
| Страноведение: культура, история, символы (Big Ben, флаги) | 5–9 | автоматически |
| Письмо: e-mail или другой текст, который класс уже учился писать по учебнику | 5–9 | **ИИ (Claude)** по выработанным критериям |
| ~~Устная часть~~ | — | **убрана во всех классах** |

**Время.** Задания рассчитаны на 40 минут в 5–6 классах и на 60 минут в 7–9 классах. Таймер — на 15–20 минут больше, с запасом.

**Письмо проверяет ИИ.** Ответы сохраняются туда, где их видит Claude. До олимпиады проверку отрабатываем на пробных работах и вместе вырабатываем критерии.

## 4. Итоги и награды

**Статус — по сумме баллов за всю олимпиаду** (предложение, баллы уточним после тестового прогона):

| статус | баллы из 100 |
|---|---|
| Победитель | 85–100 |
| Призёр | 65–84 |
| Участник | 64 и меньше |

**Объявляем заранее:** сертификат каждому участнику.

**Сюрприз после олимпиады** (примерно, утверждаем после готовности заданий):

| статус | сертификат | приз |
|---|---|---|
| Победитель | сертификат победителя | WowSpace на месяц |
| Призёр | сертификат призёра | WowSpace со скидкой 50 % |
| Участник | сертификат участника | 2 бесплатных посещения по подписке |

Сертификаты разрабатываем сами: три вида — победитель, призёр, участник.

## 5. Гости олимпиады

- Ученик делится ссылкой, гость проходит олимпиаду наравне со всеми.
- **Идея:** вход через короткую регистрацию. Тогда школа видит новых детей и может пригласить их учиться.
- Нужно согласие родителей на обработку данных и на связь со школой. Уточнить с юристом.

## 7. Риски

| риск | что делаем |
|---|---|
| Ответы со статической HTML-страницы надо где-то хранить | договориться с командой сайта, куда сохраняются ответы; Claude должен их видеть |
| Списывание дома | таймер, одна попытка, перемешанный порядок заданий, короткое окно |
| В январе в школе пройдена примерно половина учебника, а олимпиада — по всему году | задания по второй половине учебника — посильные, в основном лексика |
| ИИ ошибается в оценке письма | критерии отрабатываем заранее, спорные работы и претенденты на дипломы — на просмотр методисту |
| Технический сбой у ребёнка | инструкция для родителей, контакт поддержки на время олимпиады |
