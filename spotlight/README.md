# Грамматика Spotlight 3–11

`Spotlight_грамматика.xlsx` — грамматика по учебникам Spotlight: класс → модуль → урок → тема,
объём в каждом месте, примеры, комментарии; сводка по темам через все классы; Use of English отдельно.

Источники (папка `Spotlight` на общем диске): грамматика — только грамматический справочник учебника
и таблица неправильных глаголов; урок — по оглавлению; Use of English — оглавление и приложения
(фразовые глаголы, предлоги, идиомы). Word List не используется. 2 класса нет — в нём нет справочника.

`data/gN.json` — строки по классам, `data/full.json` — колонка «Полный объём темы».
`SPEC.md` + `CLEAN.md` — правила составления строк. Пересобрать: `python3 spotlight/build.py`.

## План уроков

`Spotlight_темы_уроков.xlsx` — планировщик уроков: подтема × класс (модуль + новое/расширение/повторение),
возрастная группа вебинара (7–9 = Spotlight 2–3, 10+ = Spotlight 4–11), отметки о видео,
структура папок `Spotlight / класс / модуль / тема`, итоги. Собирается `python3 spotlight/matrix.py`
из `data/subtopics/*.json` (разбивка тем на подтемы) и `data/gN.json` (Use of English); уже записанные вебинары — в `data/videos.json`
(`{"тема": {"7–9": "название/ссылка", "10+": "..."}}`).
