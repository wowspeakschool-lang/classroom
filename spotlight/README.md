# Грамматика Spotlight 2–11

`Spotlight_грамматика.xlsx` — таблицы грамматики по учебникам Spotlight: класс → модуль → урок → тема,
объём в каждом месте, примеры, комментарии; сводка по темам через все классы; Use of English отдельно.

Источник — PDF в папке `Spotlight` на общем диске (оглавление, грамматический справочник, Word List).
`data/gN.json` — строки по классам, `data/full.json` — колонка «Полный объём темы».
`SPEC.md` — правила, по которым составлялись строки. Пересобрать: `python3 spotlight/build.py`.
