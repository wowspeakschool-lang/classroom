# Чистка: грамматика ТОЛЬКО из грамматического справочника

Методист уточнила правила:
- Use of English (фразовые глаголы, словообразование, зависимые предлоги, words often confused) — ОСТАВИТЬ,
  но строить ТОЛЬКО по оглавлению (раздел English in Use / Use of English: какой глагол, какая модель
  словообразования) и по приложениям учебника (Appendix: Phrasal Verbs, Prepositions и т.п.), если они есть.
  Всё, что в этих строках взято из Word List, — убрать. Если от темы есть только заголовок в оглавлении —
  оставить строку с заголовком, scope = что сказано в оглавлении, comment = "в доступных страницах
  только заголовок из оглавления". Если приложение даёт список (например, фразовые глаголы с get) —
  расписать полностью с значениями.
- Грамматику брать ТОЛЬКО из Грамматического справочника (Grammar Reference / Грамматический справочник)
  и таблицы Irregular Verbs при нём.
- Word List НЕ использовать вообще: ни как источник тем, ни для объёма, ни для примеров.
- Оглавление (ToC) для грамматики — только чтобы указать урок (1a, 2c), если тема есть в справочнике.
  Грамматическую тему, которая есть только в оглавлении, а в справочнике нет, — НЕ включать
  (перечисли такие в отчёте).

Что сделать с твоим JSON-файлом (перезаписать его же):
1. Лексические строки (Use of English) перестроить по правилу выше.
2. Грамматические строки без справочника (source без GR) — удалить.
3. В оставшихся строках сверить scope/example/comment с текстом справочника (исходник ниже):
   убрать всё, что взято из Word List или домыслено; ДОБАВИТЬ то, что в справочнике есть, а в строке
   пропущено (формы, значения, орфография, сигнальные слова, исключения, примечания NOTE).
   Пример — только из справочника. Объём расписать максимально подробно по справочнику.
4. Пройти справочник целиком и добавить строки для тем, которых в файле нет вовсе.
5. source грамматики: "GR" (или "GR, ToC" если урок взят из оглавления); лексики: "ToC" / "Appendix". В comment не ссылаться на Word List;
   убрать упоминания 2 класса (у 2 класса справочника нет — он выпадает). Пометку "проверить: ..."
   оставлять только для неразборчивого OCR/скана или неуверенного урока.
6. Для 2–4 классов: справочник идёт по модулям, поле lesson сделать пустым (юниты брались из Word List).
   Название модуля оставить.
Формат строк и канонические названия тем — как в SPEC.md (рядом). Строки 2 класса удалить все.
В конце: путь к файлу, число строк было/стало, список тем «только в оглавлении, нет в справочнике».
